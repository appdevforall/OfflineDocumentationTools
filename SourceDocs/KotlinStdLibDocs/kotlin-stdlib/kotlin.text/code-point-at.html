codePointAt

inline fun String.codePointAt(index: Int): Int(source)

Returns the character (Unicode code point) at the specified index.

This function delegates to java.lang.String.codePointAt, refer to the corresponding documentation for more details on function's behavior.

Since Kotlin

1.0

Parameters

index

the index of Char whose codepoint value is needed.

Throws

IndexOutOfBoundsException

if the index is negative or greater or equal to length of this string.

// Returns a code point value corresponding to the low surrogate
