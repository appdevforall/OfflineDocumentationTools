ProfileInstallReceiver Artifact: androidx.profileinstaller:profileinstaller View Source Added in 1.0.0 Kotlin | Java public class ProfileInstallReceiver extends BroadcastReceiver java.lang.Object    ↳ android.content.BroadcastReceiver      ↳ androidx.profileinstaller.ProfileInstallReceiver The android.content.BroadcastReceiver which forces a synchronous installation of the baseline profile. This is primarily used by tools to force a synchronous install of the baseline profile without starting the application's main activity. It is not expected for this receiver to be used at runtime by anything other than tools, and as such, the action filter is defined with the "dump" permission.
