TestLifecycleOwner Artifact: androidx.lifecycle:lifecycle-runtime-testing View Source Added in 2.3.0 Kotlin | Java public final class TestLifecycleOwner implements LifecycleOwner Create a LifecycleOwner that allows changing the state via the handleLifecycleEvent method or currentState property. Under the hood, this uses a LifecycleRegistry . However, it uses Dispatchers.Main.immediate as the default coroutineDispatcher to ensure that all mutations to the current state are run on that dispatcher, no matter what thread you mutate the state from.
