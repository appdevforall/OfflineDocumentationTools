MediatorLiveData Artifact: androidx.lifecycle:lifecycle-livedata View Source Added in 2.0.0 Kotlin | Java public class MediatorLiveData <T> extends MutableLiveData java.lang.Object    ↳ androidx.lifecycle.LiveData      ↳ androidx.lifecycle.MutableLiveData        ↳ androidx.lifecycle.MediatorLiveData LiveData subclass which may observe other LiveData objects and react on OnChanged events from them. This class correctly propagates its active/inactive states down to source LiveData objects. Consider the following scenario: we have 2 instances of LiveData , let's name them liveData1 and liveData2 , and we want to merge their emissions in one MediatorLiveData object: liveDataMerger . Then, liveData1 and liveData2 will become sources for the liveDataMerger and every time onChanged callback is called for either of them, we set a new value in liveDataMerger . LiveData<Integer> liveData1 = ...; LiveData<Integer> liveData2 = ...; MediatorLiveData<Integer> liveDataMerger = new MediatorLiveData<>(); liveDataMerger.addSource(liveData1, value -> liveDataMerger.setValue(value)); liveDataMerger.addSource(liveData2, value -> liveDataMerger.setValue(value)); Let's consider that we only want 10 values emitted by liveData1 , to be merged in the liveDataMerger .
