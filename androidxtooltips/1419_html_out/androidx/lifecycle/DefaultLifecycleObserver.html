DefaultLifecycleObserver Artifact: androidx.lifecycle:lifecycle-common View Source Added in 2.4.0 Kotlin | Java public interface DefaultLifecycleObserver extends LifecycleObserver Known direct subclasses AmbientLifecycleObserver AmbientLifecycleObserver Interface for LifecycleObservers which are used to add ambient mode support to activities on Wearable devices. Callback interface for listening to LifecycleOwner state changes. If a class implements both this interface and LifecycleEventObserver , then methods of DefaultLifecycleObserver will be called first, and then followed by the call of LifecycleEventObserver.onStateChanged If a class implements this interface and in the same time uses OnLifecycleEvent, then annotations will be ignored.
