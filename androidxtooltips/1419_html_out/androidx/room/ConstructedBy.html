A androidx.room.RoomDatabase database definition must be annotated with this annotation if it is located in a common source set on a Kotlin Multiplatform project such that at runtime the implementation generated by the annotation processor can be used. The value must be an 'expect object' that implements androidx.room.RoomDatabaseConstructor .
