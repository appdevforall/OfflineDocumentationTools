Since a io.reactivex.Single must either emit a single non-null value or an error, this exception is thrown instead of emitting a null value when the query resulted empty. If the io.reactivex.Single contains a type argument of a collection (e.g. Single<List<Song>> ) the this exception is not thrown an an empty collection is emitted instead.
