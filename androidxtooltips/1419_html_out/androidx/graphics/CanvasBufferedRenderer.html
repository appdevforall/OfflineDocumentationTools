CanvasBufferedRenderer Artifact: androidx.graphics:graphics-core View Source Added in 1.0.3 Kotlin | Java @ RequiresApi (value = 29) public final class CanvasBufferedRenderer implements AutoCloseable Creates an instance of a hardware-accelerated renderer. This is used to render a scene built from RenderNode s to an output HardwareBuffer . There can be as many CanvasBufferedRenderer instances as desired. Resources & lifecycle All CanvasBufferedRenderer instances share a common render thread. Therefore CanvasBufferedRenderer will share common resources and GPU utilization with hardware accelerated rendering initiated by the UI thread of an application. The render thread contains the GPU context & resources necessary to do GPU-accelerated rendering. As such, the first CanvasBufferedRenderer created comes with the cost of also creating the associated GPU contexts, however each incremental CanvasBufferedRenderer thereafter is fairly cheap. This is useful in situations where a scene built with RenderNode . CanvasBufferedRenderer can optionally persist contents before each draw invocation so previous contents in the HardwareBuffer target will be preserved across renders. This is determined by the argument provided to CanvasBufferedRenderer.RenderRequest.preserveContents which is set to false by default.
