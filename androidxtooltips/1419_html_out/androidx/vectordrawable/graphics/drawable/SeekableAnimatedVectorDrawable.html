SeekableAnimatedVectorDrawable supports the following features too: Path Morphing (PathType evaluator). This is used for morphing one path into another. Path Interpolation. This is used to defined a flexible interpolator (represented as a path) instead of the system defined ones like LinearInterpolator. Animating 2 values in one ObjectAnimator according to one path's X value and Y value. One usage is moving one object in both X and Y dimensions along an path. Unlike AnimatedVectorDrawableCompat , this class does not delegate to the platform android.graphics.drawable.AnimatedVectorDrawable on any API levels.
