ActivityResultContracts.StartIntentSenderForResult Artifact: androidx.activity:activity View Source Added in 1.2.0 Kotlin | Java public final class ActivityResultContracts.StartIntentSenderForResult extends ActivityResultContract java.lang.Object    ↳ androidx.activity.result.contract.ActivityResultContract      ↳ androidx.activity.result.contract.ActivityResultContracts.StartIntentSenderForResult An ActivityResultContract that calls Activity.startIntentSender . This ActivityResultContract takes an IntentSenderRequest , which must be constructed using an IntentSenderRequest.Builder . If the call to Activity.startIntentSenderForResult throws an android.content.IntentSender.SendIntentException the androidx.activity.result.ActivityResultCallback will receive an ActivityResult with an Activity.RESULT_CANCELED resultCode and whose intent has the action of ACTION_INTENT_SENDER_REQUEST and an extra EXTRA_SEND_INTENT_EXCEPTION that contains the thrown exception.
