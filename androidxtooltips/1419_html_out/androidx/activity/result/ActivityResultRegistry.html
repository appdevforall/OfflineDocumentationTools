ActivityResultRegistry Artifact: androidx.activity:activity View Source Added in 1.2.0 Kotlin | Java public abstract class ActivityResultRegistry A registry that stores activity result callbacks for registered calls . You can create your own instance for testing by overriding onLaunch and calling dispatchResult immediately within it, thus skipping the actual Activity.startActivityForResult call. When testing, make sure to explicitly provide a registry instance whenever calling ActivityResultCaller.registerForActivityResult , to be able to inject a test instance.
