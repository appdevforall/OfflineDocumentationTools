ContextAwareHelper Artifact: androidx.activity:activity View Source Added in 1.2.0 Kotlin | Java public final class ContextAwareHelper Helper class for implementing ContextAware . Classes using this helper should call addOnContextAvailableListener and removeOnContextAvailableListener as the respective methods of ContextAware are called. You must call dispatchOnContextAvailable once the Context is available to dispatch the callbacks to all registered listeners. Listeners added after the context has been made available via dispatchOnContextAvailable will have the Context synchronously delivered to them up until clearAvailableContext is called.
