MarginPageTransformer Artifact: androidx.viewpager2:viewpager2 View Source Added in 1.0.0 Kotlin | Java public final class MarginPageTransformer implements ViewPager2.PageTransformer Adds space between pages via the ViewPager2.PageTransformer API. Internally relies on setTranslationX and setTranslationY . Note: translations on pages are not reset when this adapter is changed for another one, so you might want to set them manually to 0 when dynamically switching to another transformer, or when switching ViewPager2 orientation.
