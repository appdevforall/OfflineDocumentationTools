ProxyController Artifact: androidx.webkit:webkit View Source Added in 1.1.0 Kotlin | Java @ AnyThread public abstract class ProxyController Manages setting and clearing a process-specific override for the Android system-wide proxy settings that govern network requests made by android.webkit.WebView . WebView may make network requests in order to fetch content that is not otherwise read from the file system or provided directly by application code. In this case by default the system-wide Android network proxy settings are used to redirect requests to appropriate proxy servers. In the rare case that it is necessary for an application to explicitly specify its proxy configuration, this API may be used to explicitly specify the proxy rules that govern WebView initiated network requests. Example usage: ProxyConfig proxyConfig = new ProxyConfig.Builder().addProxyRule("myproxy.com") .addBypassRule("www.excluded.*") .build(); Executor executor = ... Runnable listener = ...
