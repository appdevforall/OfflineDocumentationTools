Public constructors WebViewRenderProcess Added in 1.1.0 public  WebViewRenderProcess () Public methods terminate Added in 1.1.0 public abstract boolean  terminate () Cause this renderer to terminate. Calling this on a not yet started, or an already terminated renderer will have no effect. Terminating a renderer process may have an effect on multiple android.webkit.WebView instances. RenderProcess termination must be handled by properly overriding onRenderProcessGone for every WebView that shares this renderer. If termination is not handled by all associated WebViews, then the application process will also be terminated. This method should only be called if isFeatureSupported returns true for WEB_VIEW_RENDERER_TERMINATE . Returns boolean true if it was possible to terminate this renderer, false otherwise.
