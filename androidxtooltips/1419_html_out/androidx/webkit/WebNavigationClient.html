WebNavigationClient Artifact: androidx.webkit:webkit View Source Added in 1.14.0 Kotlin | Java @ WebNavigationClient.ExperimentalNavigationCallback public interface WebNavigationClient Page identification and lifecycle APIs. This class provides callbacks to identify the different stages of navigation. For more information about the navigation lifecycle, please see the Life of a Navigation Presentation . Note: These navigation callbacks only fire for navigations happening on the main frame.
