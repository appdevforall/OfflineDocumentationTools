Public methods getDragToOpenListener Added in 1.1.0 public static @ Nullable View.OnTouchListener   getDragToOpenListener (@ NonNull Object  popupMenu) On API KITKAT and higher, returns an OnTouchListener that can be added to the anchor view to implement drag-to-open behavior. When the listener is set on a view, touching that view and dragging outside of its bounds will open the popup window. Lifting will select the currently touched list item. Example usage: PopupMenu myPopup = new PopupMenu(context, myAnchor); myAnchor.setOnTouchListener(PopupMenuCompat.getDragToOpenListener(myPopup)); Parameters @ NonNull Object  popupMenu the PopupMenu against which to invoke the method Returns @ Nullable View.OnTouchListener a touch listener that controls drag-to-open behavior, or null on unsupported APIs
