DisplayCompat Artifact: androidx.core:core View Source Added in 1.3.0 Kotlin | Java public final class DisplayCompat A class for retrieving accurate display modes for a display. On many Android TV devices, Display.Mode may not report the accurate width and height because these devices do not have powerful enough graphics pipelines to run framework code at the same resolutions supported by their video pipelines. For these devices, there is no way for an app to determine, for example, whether or not the current display mode is 4k, or that the display supports switching to other 4k modes. This class offers a workaround for this problem.
