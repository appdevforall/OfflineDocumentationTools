WindowInsetsAnimationControllerCompat Artifact: androidx.core:core View Source Added in 1.5.0 Kotlin | Java public final class WindowInsetsAnimationControllerCompat Controller for app-driven animation of system windows. WindowInsetsAnimationController lets apps animate system windows such as the IME . The animation is synchronized, such that changes the system windows and the app's current frame are rendered at the same time. Control is obtained through controlWindowInsetsAnimation . Note that these insets are always relative to the window, which is the same as being relative to getRootView Also note that this will not inform the view system of a full inset change via dispatchApplyWindowInsets in order to avoid a full layout pass during the animation. If you'd like to animate views during a window inset animation, register a WindowInsetsAnimationCompat.Callback by calling setWindowInsetsAnimationCallback that will be notified about any insets change via onProgress during the animation. dispatchApplyWindowInsets will instead be called once the animation has finished, i.e. once finish has been called. Note that these insets are being clamped to the range from getHiddenStateInsets to getShownStateInsets .
