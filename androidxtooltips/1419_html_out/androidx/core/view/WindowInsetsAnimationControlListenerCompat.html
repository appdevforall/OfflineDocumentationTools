WindowInsetsAnimationControlListenerCompat Artifact: androidx.core:core View Source Added in 1.5.0 Kotlin | Java public interface WindowInsetsAnimationControlListenerCompat Listener that encapsulates a request to controlWindowInsetsAnimation . Insets can be controlled with the supplied WindowInsetsAnimationControllerCompat from onReady until either onFinished or onCancelled . Once the control over insets is finished or cancelled, it will not be regained until a new request to controlWindowInsetsAnimation is made. The request to control insets can fail immediately. In that case onCancelled will be invoked without a preceding onReady .
