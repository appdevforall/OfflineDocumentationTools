Public methods isSupported Added in 1.0.0 abstract boolean  isSupported () Whether or not the call icon extension is supported by the calling application. If true , then updates about icon in the call will be notified. If false , then the remote doesn't support this extension and icons will not be notified to the caller nor will associated actions receive state updates. Note: Must not be queried until after CallExtensionScope.onConnected is called.
