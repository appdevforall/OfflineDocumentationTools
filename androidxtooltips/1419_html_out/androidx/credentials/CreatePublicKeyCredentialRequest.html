When set to true, it is important to note that no dialog like system UI is shown to the user, and instead the credential provider is to show a notification to the user when passkey creation is successful. Ideal scenarios to set this to true are when making a request immediately after a successful, non-passkey sign-in (e.g. sign-in using a password), or an independent sign-up process
