CreateEntry Artifact: androidx.credentials:credentials View Source Added in 1.2.0 Kotlin | Java @ RequiresApi (value = 23) public final class CreateEntry An entry to be shown on the selector during a create flow initiated when an app calls CredentialManager.createCredential A CreateEntry points to a location such as an account, or a group where the credential can be registered. When user selects this entry, the corresponding PendingIntent is fired, and the credential creation can be completed.
