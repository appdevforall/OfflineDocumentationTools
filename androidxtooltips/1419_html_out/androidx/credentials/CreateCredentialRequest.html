CreateDigitalCredentialRequest A request to save a digital credential to a holder application of the user's choice. CreatePasswordRequest A request to save the user password credential with their password provider. CreatePublicKeyCredentialRequest A request to register a passkey from the user's public key credential provider. CreateRestoreCredentialRequest A request to create a restore credential used for app restore purpose. Base request class for registering a credential. An application can construct a subtype request and call CredentialManager.createCredential to launch framework UI flows to collect consent and any other metadata needed from the user to register a new user credential.
