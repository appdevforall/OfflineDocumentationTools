OverlayScene Artifact: androidx.navigation3:navigation3-ui View Source Added in 1.0.0-alpha05 Kotlin | Java public interface OverlayScene <T extends  Object > extends Scene A specific scene to render 1 or more NavEntry instances as an overlay. It is expected that the content is rendered in one or more separate windows (e.g., a dialog, popup window, etc.) that are visible above any additional Scene instances calculated from the overlaidEntries . When processing overlaidEntries , expect processing of each SceneStrategy to restart from the first strategy. This may result in multiple instances of the same OverlayScene to be shown simultaneously, making a unique key even more important.
