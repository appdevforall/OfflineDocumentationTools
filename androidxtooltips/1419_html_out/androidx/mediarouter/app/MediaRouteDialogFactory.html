MediaRouteDialogFactory Artifact: androidx.mediarouter:mediarouter View Source Added in 1.1.0 Kotlin | Java public class MediaRouteDialogFactory The media route dialog factory is responsible for creating the media route chooser and controller dialogs as needed. The application can customize the dialogs by providing a subclass of the dialog factory to the MediaRouteButton using the setDialogFactory method.
