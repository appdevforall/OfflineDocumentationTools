Public methods onPrepareTransfer Added in 1.2.0 @ MainThread abstract @ Nullable ListenableFuture < Void >  onPrepareTransfer (     @ NonNull MediaRouter.RouteInfo  fromRoute,     @ NonNull MediaRouter.RouteInfo  toRoute ) Implement this to handle transfer seamlessly. Setting the listener will defer stopping the previous route, from which you may get the media status to resume media seamlessly on the new route. When the transfer is prepared, set the returned future to stop media being played on the previous route and release resources. This method is called on the main thread. onRouteUnselected and onRouteSelected are called after the future is done. Parameters @ NonNull MediaRouter.RouteInfo  fromRoute The route that is about to be unselected. @ NonNull MediaRouter.RouteInfo  toRoute The route that is about to be selected. Returns @ Nullable ListenableFuture < Void > A ListenableFuture whose completion indicates that the transfer is prepared or null to indicate that no preparation is needed. If a future is returned, until the future is completed, the media continues to be played on the previous route.
