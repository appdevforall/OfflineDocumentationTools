ReplaceFileCorruptionHandler Artifact: androidx.datastore:datastore-core View Source Added in 1.0.0 Kotlin | Java public final class ReplaceFileCorruptionHandler <T extends  Object > A corruption handler that attempts to replace the on-disk data with data from produceNewData. If the handler successfully replaces the data, the original exception is swallowed. If the handler encounters an exception when attempting to replace data, the new exception is added as a suppressed exception to the original exception and the original exception is thrown.
