GuidedActionEditText A custom EditText that satisfies the IME key monitoring requirements of GuidedStepFragment. Interface for an EditText subclass that can delegate calls to onKeyPreIme up to a registered listener. Used in editable actions within androidx.leanback.app.GuidedStepFragment to allow for custom back key handling. Specifically, this is used to implement the behavior that dismissing the IME also clears edit text focus. Clients who need to supply custom layouts for GuidedActionsStylist with their own EditText classes should satisfy this interface in order to inherit this behavior.
