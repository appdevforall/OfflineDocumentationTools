FacetProviderAdapter Artifact: androidx.leanback:leanback-grid View Source Added in 1.0.0 Kotlin | Java public interface FacetProviderAdapter Known direct subclasses ItemBridgeAdapter ItemBridgeAdapter Bridge from Presenter to RecyclerView.Adapter . Optional interface that implemented by androidx.recyclerview.widget.RecyclerView.Adapter to query FacetProvider for a given item view type within Adapter. Note that androidx.recyclerview.widget.RecyclerView.ViewHolder may also implement FacetProvider which has a higher priority than the one returned from getFacetProvider . A typical use case of FacetProvider is that VerticalGridView/HorizontalGridView retrieves ItemAlignmentFacet for a ViewHolder or a item view type.
