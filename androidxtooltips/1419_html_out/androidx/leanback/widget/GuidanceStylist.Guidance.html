GuidanceStylist.Guidance Artifact: androidx.leanback:leanback View Source Added in 1.1.0 Kotlin | Java public class GuidanceStylist.Guidance A data class representing contextual information for a . Guidance consists of a short title, a longer description, a breadcrumb to help with global navigation (often indicating where the back button will lead), and an optional icon. All this information is intended to provide users with the appropriate context to make the decision(s) required by the current step. Clients may provide a subclass of this if they wish to remember auxiliary data for use in a customized GuidanceStylist.
