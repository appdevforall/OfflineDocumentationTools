ApplicationProvider Artifact: androidx.test:core View Source Kotlin | Java public final class ApplicationProvider Provides ability to retrieve the current application Context in tests. This can be useful if you need to access the application assets (eg getApplicationContext().getAssets() ), preferences (eg getApplicationContext().getSharedPreferences() ), file system (eg getApplicationContext().getDir() ) or one of the many other context APIs in test.
