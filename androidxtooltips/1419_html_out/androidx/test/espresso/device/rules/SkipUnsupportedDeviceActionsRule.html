SkipUnsupportedDeviceActionsRule Artifact: androidx.test.espresso:espresso-device View Source Kotlin | Java public final class SkipUnsupportedDeviceActionsRule implements TestRule Rule for skipping tests when a device action is called on an unsupported device. DeviceActions throw UnsupportedDeviceOperationExceptions when actions cannot be performed on the test device. This rule catches those exceptions and skips the tests where they are thrown. Without this rule, tests will fail when a device action is performed on an unsupported device.
