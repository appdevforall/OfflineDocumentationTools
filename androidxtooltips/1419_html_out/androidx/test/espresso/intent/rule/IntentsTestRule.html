This rule makes it easy to use Espresso-Intents APIs in functional UI tests. This class is an extension of ActivityTestRule , which initializes Espresso-Intents before each test annotated with org.junit.Test and releases Espresso-Intents after each test run. The Activity will be terminated after each test and this rule can be used in the same way as .
