IdlingPolicies Artifact: androidx.test.espresso:espresso-core View Source Kotlin | Java public final class IdlingPolicies Allows users fine grain control over idling policies. Espresso's default idling policies are suitable for most usecases - however certain execution environments (like the ARM emulator) might be very slow. This class allows users the ability to adjust defaults to sensible values for their environments.
