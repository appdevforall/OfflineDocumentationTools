Importantly, it assumes the getItemId matches a valid androidx.navigation.NavDestination.getAction or destination id to be navigated to. By default, the back stack will be popped back to the navigation graph's start destination. Menu items that have android:menuCategory="secondary" will not pop the back stack. Returns boolean True if the NavController was able to navigate to the destination.
