AggregateGroupByPeriodRequest Artifact: androidx.health.connect:connect-client View Source Added in 1.1.0-rc02 Kotlin | Java public final class AggregateGroupByPeriodRequest Request object to read time bucketed aggregations for given AggregateMetric s in Android Health Platform. timeRangeSlicer contains a Period of variable length time intervals, such as per day, which may be anywhere between 23, 24, or 25 hour.
