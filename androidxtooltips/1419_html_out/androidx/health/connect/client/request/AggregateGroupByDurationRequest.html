AggregateGroupByDurationRequest Artifact: androidx.health.connect:connect-client View Source Added in 1.1.0-rc02 Kotlin | Java public final class AggregateGroupByDurationRequest Request object to read time bucketed aggregations for given AggregateMetric s in Android Health Platform. timeRangeSlicer contains a Duration of fixed physical time intervals, such as per hour, per ten minutes or so.
