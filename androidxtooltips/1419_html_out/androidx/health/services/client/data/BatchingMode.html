This setting significantly increases power consumption, and is intended to be used by apps which need to send data to a separate device (e.g. a connected phone or TV) for real-time visualisation. It has no effect if the device is interactive. The exact power/performance tradeoff of this mode is device implementation dependent and batched updates may be aligned with other wake ups but target five second updates.
