PropertyRestrictNode Artifact: androidx.appsearch:appsearch View Source Added in 1.1.0 Kotlin | Java @ ExperimentalAppSearchApi public final class PropertyRestrictNode implements Node Node that represents a property restrict. A property restrict is an expression in the query language that allows a querier to restrict the results of a query expression to those contained in a given property path. Written as a query string, this node should be equivalent to the query `property:child`, where `property` is the property path to restrict results to and `child` is the query subexpression. This node is a comparator that should correspond with HAS in the Google AIP EBNF Filtering Definition .
