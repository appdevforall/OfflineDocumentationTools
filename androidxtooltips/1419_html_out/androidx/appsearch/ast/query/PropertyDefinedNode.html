PropertyDefinedNode Artifact: androidx.appsearch:appsearch View Source Added in 1.1.0 Kotlin | Java @ ExperimentalAppSearchApi public final class PropertyDefinedNode implements FunctionNode FunctionNode representing the `propertyDefined` query function. The `propertyDefined` query function will return all documents of types that define the given property. This will include documents that do not have the property itself, so long as that property is a part of the document's schema. If you need to restrict to documents that have >=1 value(s) populated for that property, see HasPropertyNode .
