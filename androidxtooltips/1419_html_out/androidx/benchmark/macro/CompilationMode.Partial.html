The default parameters for this mimic the default state of an app partially pre-compiled by the installer - such as via Google Play. Either baselineProfileMode must be set to non- BaselineProfileMode.Disable , or warmupIterations must be set to a non- 0 value. Note: [baselineProfileMode] = [BaselineProfileMode.Require] is only supported for APKs that have the ProfileInstaller library included, and have been built by AGP 7.0+ to package the baseline profile in the APK.
