There are two modes for measurement - Last , which represents the last observed value during an iteration, and Max , which represents the largest sample observed per measurement. By default, reports: memoryRssAnonKb - Anonymous resident/allocated memory owned by the process, not including memory mapped files or shared memory. memoryRssAnonFileKb - Memory allocated by the process to map files. memoryHeapSizeKb - Heap memory allocations from the Android Runtime, sampled after each GC. memoryGpuKb - GPU Memory allocated for the process. By passing a custom subMetrics list, you can enable other SubMetric s.
