ProcessCameraProvider A singleton which can be used to bind the lifecycle of cameras to any LifecycleOwner within an application's process. A CameraProvider provides basic access to a set of cameras such as querying for camera existence or information. A device might have multiple cameras. According to the applications' design, they might need to search for a suitable camera which supports their functions. A CameraProvider allows the applications to check whether any camera exists to fulfill the requirements or to get CameraInfo instances of all cameras to retrieve the camera information.
