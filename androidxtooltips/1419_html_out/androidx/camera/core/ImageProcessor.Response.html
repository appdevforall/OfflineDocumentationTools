ImageProcessor should implement the ImageProxy and ImageProxy.PlaneProxy interfaces to create the return value. Once return, CameraX will inject the image back to the processing pipeline. The ImageProxy must follow the instruction in the request, or CameraX may throw error. For example, the image format must match the description of the getOutputFormat .
