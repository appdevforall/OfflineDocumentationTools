FlashState Artifact: androidx.camera:camera-core View Source Added in 1.5.0-beta01 Kotlin | Java public static class FlashState The camera flash state values represent the state of the physical flash unit of a camera. The possible values are UNKNOWN , FIRED , UNAVAILABLE , and NOT_FIRED . In case of any error, how it is notified depends on the API that is used for obtaining the FlashState . For example, if the flash state is obtained by invoking ImageCapture.takePicture(Executor, OnImageCapturedCallback) and using the returned ImageProxy to use ImageInfo.getFlashState , any related error will be notified via OnImageCapturedCallback.onError .
