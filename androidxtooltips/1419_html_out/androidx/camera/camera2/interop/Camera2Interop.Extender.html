In the case one logical camera is made up of multiple physical cameras, this call forces the physical camera with the specified camera ID to produce image. The valid physical camera IDs can be queried by CameraCharacteristics .getPhysicalCameraIds on API >= 28. Passing in an invalid physical camera ID will be ignored.
