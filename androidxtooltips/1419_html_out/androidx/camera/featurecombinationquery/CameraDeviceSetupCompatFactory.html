The returned instance aggregates the results from both the Play Services and the Android framework. It first checks if a Play Services implementation exists, and if so, return the query result from the Play Services implementation. If no Play Services implementation exists or the result from Play Services is undefined, the returned instance will then query Android framework for the result, if running on a new enough version. If the return value is RESULT_UNDEFINED , on API level between 29 and 34 inclusive, it's also possible to further check if the session configuration is supported by querying the isSessionConfigurationSupported . This approach requires opening the camera first which may introduce latency, so the AndroidX implementation does not include this code path by default. Additionally, this approach does not check the values set in setSessionParameters . For example, the FPS range is ignored.
