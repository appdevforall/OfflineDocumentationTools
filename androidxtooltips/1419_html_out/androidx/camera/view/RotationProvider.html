RotationProvider Artifact: androidx.camera:camera-view View Source Added in 1.1.0 Kotlin | Java public final class RotationProvider Provider for receiving rotation updates from the SensorManager when the rotation of the device has changed. This class monitors motion sensor and notifies the listener about physical orientation changes in the format of Surface rotation. It's useful when the Activity is in a fixed portrait or landscape orientation, while the app still wants to set the UseCase target rotation based on the device's physical rotation. // Create a provider.
