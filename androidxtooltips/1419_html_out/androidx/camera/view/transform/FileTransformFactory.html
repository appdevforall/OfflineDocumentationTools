FileTransformFactory Artifact: androidx.camera:camera-view View Source Added in 1.1.0 Kotlin | Java public final class FileTransformFactory Factory for extracting transform info from image files. This class is for extracting a OutputTransform from an image file saved by ImageCapture . The OutputTransform represents the transform being applied to the original camera buffer, which can be used by CoordinateTransform to transform coordinates between UseCase s.
