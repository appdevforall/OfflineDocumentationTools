Public constructors RangeBuilder Added in 1.1.0-alpha02 public  RangeBuilder () Builder to construct a range row which can be added to a ListBuilder . A range row supports displaying a horizontal progress indicator. It supports two modes to represent progress: determinate and indeterminate, see setMode . Determinate mode is the default for progress indicator.
