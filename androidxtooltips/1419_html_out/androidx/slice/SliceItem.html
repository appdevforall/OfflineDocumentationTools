SliceItem Artifact: androidx.slice:slice-core View Source Added in 1.1.0-alpha02 Kotlin | Java @ RequiresApi (value = 19) public final class SliceItem implements VersionedParcelable A SliceItem is a single unit in the tree structure of a Slice . A SliceItem a piece of content and some hints about what that content means or how it should be displayed. The types of content can be: FORMAT_SLICE FORMAT_TEXT FORMAT_IMAGE FORMAT_ACTION FORMAT_INT FORMAT_LONG The hints that a SliceItem are a set of strings which annotate the content. The hints that are guaranteed to be understood by the system are defined on Slice .
