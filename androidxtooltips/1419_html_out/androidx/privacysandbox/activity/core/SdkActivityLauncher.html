LocalUnmanagedSdkActivityLauncher Local implementation of an SDK Activity launcher. Interface that allows SDKs running in the Privacy Sandbox to launch activities. Apps can create launchers by calling createManagedSdkActivityLauncher or createUnmanagedSdkActivityLauncher from one of their activities. To send an SdkActivityLauncher to another process, they can call toLauncherInfo and send the resulting bundle. SDKs can create launchers from an app-provided bundle by calling fromLauncherInfo .
