SandboxedSdkCompat Artifact: androidx.privacysandbox.sdkruntime:sdkruntime-core View Source Added in 1.0.0-alpha17 Kotlin | Java public final class SandboxedSdkCompat Compat wrapper for SandboxedSdk . Represents an SDK loaded in the sandbox process or locally. An application should use this object to obtain an interface to the SDK through getInterface . The SDK should create it when SandboxedSdkProviderCompat.onLoadSdk is called, and drop all references to it when SandboxedSdkProviderCompat.beforeUnloadSdk is called. Additionally, the SDK should fail calls made to the IBinder returned from getInterface after SandboxedSdkProviderCompat.beforeUnloadSdk has been called.
