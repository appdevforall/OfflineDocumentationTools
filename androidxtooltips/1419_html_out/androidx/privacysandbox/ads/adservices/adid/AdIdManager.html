AdIdManager Artifact: androidx.privacysandbox.ads:ads-adservices View Source Added in 1.0.0 Kotlin | Java public abstract class AdIdManager AdId Manager provides APIs for app and ad-SDKs to access advertising ID. The advertising ID is a unique, per-device, user-resettable ID for advertising. It gives users better controls and provides developers with a simple, standard system to continue to monetize their apps via personalized ads (formerly known as interest-based ads).
