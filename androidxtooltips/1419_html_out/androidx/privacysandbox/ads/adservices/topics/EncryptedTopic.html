Example of decrypted json string: {@code { "taxonomy_version": 5, "model_version": 2, "topic_id": 10010 }} Decryption of cipher text is expected to happen on the server with the corresponding algorithm and private key for the public key {@link EncryptedTopic#getKeyIdentifier()}}.
