This annotation is repeatable, and if specified multiple times, you are required to have one of (not all of) the specified extension versions. Example: @RequiresExtension ( extension = Build . VERSION_CODES . R , version = 3 ) fun methodUsingApisFromR () { ... } For the special case of extension == 0, you can instead use the RequiresApi annotation; @RequiresApi(30) is equivalent to @RequiresExtension(extension=0, version=30) .
