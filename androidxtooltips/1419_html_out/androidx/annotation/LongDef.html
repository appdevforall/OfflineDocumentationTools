LongDef Artifact: androidx.annotation:annotation View Source Added in 1.0.0 Kotlin | Java @ Retention (value = AnnotationRetention.SOURCE) @ Target (allowedTargets = [AnnotationTarget.ANNOTATION_CLASS]) public annotation LongDef Denotes that the annotated long element represents a logical type and that its value should be one of the explicitly named constants. If the LongDef#flag() attribute is set to true, multiple constants can be combined.
