IntDef Artifact: androidx.annotation:annotation View Source Added in 1.0.0 Kotlin | Java @ Retention (value = AnnotationRetention.SOURCE) @ Target (allowedTargets = [AnnotationTarget.ANNOTATION_CLASS]) public annotation IntDef Denotes that the annotated element of integer type, represents a logical type and that its value should be one of the explicitly named constants. If the IntDef#flag() attribute is set to true, multiple constants can be combined.
