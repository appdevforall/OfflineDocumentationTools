Public methods onItemVisibilityChanged Added in 1.0.0 abstract void  onItemVisibilityChanged (int startIndex, int endIndex) Notifies that the items in the list within the specified indices have become visible. The start index is inclusive, and the end index is exclusive. For example, if only the first item in a list is visible, the start and end indices would be 0 and 1, respectively. Parameters int startIndex the index of the first item that is visible int endIndex the index of the first item that is not visible after the visible range
