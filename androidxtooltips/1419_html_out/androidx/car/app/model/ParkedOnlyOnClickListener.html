ParkedOnlyOnClickListener Artifact: androidx.car.app:app View Source Added in 1.0.0 Kotlin | Java @ CarProtocol public final class ParkedOnlyOnClickListener implements OnClickListener An OnClickListener that wraps another one and executes its onClick method only when the car is parked. When the car is not parked, the handler won't be executed and the host will display a message to the user indicating that the action can only be used while parked. Actions that direct the users to their phones must only execute while parked. This class should be used for wrapping any click listeners that invoke such actions.
