LaneDirection Artifact: androidx.car.app:app View Source Added in 1.0.0 Kotlin | Java @ CarProtocol public final class LaneDirection Defines the possible directions a driver can go when using a particular lane at a particular step in the navigation. These directions can be combined and sent to the host to display a lane configuration to the user.
