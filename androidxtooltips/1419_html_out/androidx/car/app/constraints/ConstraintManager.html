ConstraintManager Artifact: androidx.car.app:app View Source Added in 1.1.0 Kotlin | Java @ RequiresCarApi (value = 2) public class ConstraintManager implements Manager Manages various constraints on the library as enforced by the host. Depending on the host the app is connected to, there could be different various limits that apply, such as the number of items that could be in a list in different templates. An app can use this manager to query for these limits at runtime and react accordingly.
