Type: INTEGER COLUMN_BROWSABLE Added in 1.1.0 default static final  String   COLUMN_BROWSABLE = "browsable" The flag indicating whether this TV program is browsable or not. This column can only be set by applications having proper system permission. For other applications, this is a read-only column. A value of 1 indicates that the program is browsable and can be shown to users in the UI. A value of 0 indicates that the program should be hidden from users and the application who changes this value to 0 should send ACTION_WATCH_NEXT_PROGRAM_BROWSABLE_DISABLED to the owner of the program to notify this change. This value is set to 1 (browsable) by default.
