PreviewChannel.Builder Artifact: androidx.tvprovider:tvprovider View Source Added in 1.1.0 Kotlin | Java public final class PreviewChannel.Builder This builder makes it easy to create a PreviewChannel object by allowing you to chain setters. Even though this builder provides a no-arg constructor, certain fields are required or the build method will throw an exception. The required fields are displayName and appLinkIntentUri; use the respective methods to set them.
