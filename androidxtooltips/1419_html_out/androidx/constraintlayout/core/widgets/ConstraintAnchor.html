ConstraintAnchor Artifact: androidx.constraintlayout:constraintlayout-core View Source Added in 1.1.1 Kotlin | Java public class ConstraintAnchor Model a constraint relation. Widgets contains anchors, and a constraint relation between two widgets is made by connecting one anchor to another. The anchor will contains a pointer to the target anchor if it is connected.
