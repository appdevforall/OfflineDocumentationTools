Motion Artifact: androidx.constraintlayout:constraintlayout-core View Source Added in 1.1.1 Kotlin | Java public class Motion implements TypedValues Contains the picture of a view through a transition and is used to interpolate it. During a transition every view has a MotionController which drives its position. All parameter which affect a views motion are added to MotionController and then setup() builds out the splines that control the view.
