MotionController Artifact: androidx.constraintlayout:constraintlayout View Source Added in 2.2.1 Kotlin | Java public class MotionController Contains the picture of a view through a transition and is used to interpolate it. During an transition every view has a MotionController which drives its position. All parameter which affect a views motion are added to MotionController and then setup() builds out the splines that control the view.
