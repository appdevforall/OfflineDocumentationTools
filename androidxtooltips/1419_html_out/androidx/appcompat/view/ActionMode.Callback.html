ActionMode.Callback Artifact: androidx.appcompat:appcompat View Source Added in 1.1.0 Kotlin | Java public interface ActionMode.Callback Callback interface for action modes. Supplied to startSupportActionMode (Callback)}, a Callback configures and handles events raised by a user's interaction with an action mode.
