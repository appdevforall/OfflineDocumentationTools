Warning: do not use this method in combination with setting any other attributes such as usage, content type, or flags, as this method will overwrite (the more accurate) information describing the use case previously set in the Builder. In general, avoid using it and prefer setting usage and content type directly with setUsage and setContentType . Use this method when building an AudioAttributes instance to initialize some of the attributes by information derived from a legacy stream type.
