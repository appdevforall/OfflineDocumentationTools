SubtitleTranscodingExtractorOutput Artifact: androidx.media3:media3-extractor View Source Kotlin | Java @ UnstableApi public final class SubtitleTranscodingExtractorOutput implements ExtractorOutput A wrapping ExtractorOutput that transcodes text samples from supported subtitle formats to APPLICATION_MEDIA3_CUES . The resulting APPLICATION_MEDIA3_CUES samples are emitted to the underlying TrackOutput . For non-text tracks (i.e. where C.TrackType is not C.TRACK_TYPE_TEXT ), samples are passed through to the underlying TrackOutput without modification. Support for subtitle formats is determined by supportsFormat on the SubtitleParser.Factory passed to the constructor of this class.
