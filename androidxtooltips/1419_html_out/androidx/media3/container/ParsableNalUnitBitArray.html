ParsableNalUnitBitArray Artifact: androidx.media3:media3-container View Source Kotlin | Java @ UnstableApi public final class ParsableNalUnitBitArray Wraps a byte array, providing methods that allow it to be read as a NAL unit bitstream. Whenever the byte sequence [0, 0, 3] appears in the wrapped byte array, it is treated as [0, 0] for all reading/skipping operations, which makes the bitstream appear to be unescaped.
