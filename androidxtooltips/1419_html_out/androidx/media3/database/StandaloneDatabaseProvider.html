Use StandaloneDatabaseProvider . An SQLiteOpenHelper that provides instances of a standalone database. Suitable for use by applications that do not already have their own database, or that would prefer to keep tables used by media library components isolated in their own database. Other applications should prefer to use DefaultDatabaseProvider with their own .
