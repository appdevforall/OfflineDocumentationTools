C.FirstFrameState Artifact: androidx.media3:media3-common View Source Kotlin | Java @ Documented @ Retention (value = RetentionPolicy.SOURCE) @ Target (value = TYPE_USE) @ UnstableApi @ IntDef (value = ) public annotation C.FirstFrameState State of the first frame in a video renderer. One of FIRST_FRAME_NOT_RENDERED_ONLY_ALLOWED_IF_STARTED , FIRST_FRAME_NOT_RENDERED , FIRST_FRAME_NOT_RENDERED_AFTER_STREAM_CHANGE or FIRST_FRAME_RENDERED . The stages are ordered and comparable, i.e., a value implies that all stages with higher values are not reached yet.
