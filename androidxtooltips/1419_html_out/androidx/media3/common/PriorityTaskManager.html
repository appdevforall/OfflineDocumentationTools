PriorityTaskManager Artifact: androidx.media3:media3-common View Source Kotlin | Java @ UnstableApi public final class PriorityTaskManager Allows tasks with associated priorities to control how they proceed relative to one another. A task should call add to register with the manager and remove to unregister. A registered task will prevent tasks of lower priority from proceeding, and should call proceed , proceedNonBlocking or proceedOrThrow each time it wishes to check whether it is itself allowed to proceed. It is recommended to use predefined priorities or priority values defined relative to those defaults.
