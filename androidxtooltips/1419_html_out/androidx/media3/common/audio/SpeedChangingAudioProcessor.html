After calling this method, call isActive to determine whether the audio processor is active. Returns the configured output audio format if this instance is active. After calling this method, it is necessary to flush the processor to apply the new configuration. Before applying the new configuration, it is safe to queue input and get output in the old input/output formats. Call queueEndOfStream when no more input will be supplied in the old input format.
