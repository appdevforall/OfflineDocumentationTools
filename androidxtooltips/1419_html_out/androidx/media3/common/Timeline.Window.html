Timeline.Window Artifact: androidx.media3:media3-common View Source Kotlin | Java public final class Timeline.Window Holds information about a window in a Timeline . A window usually corresponds to one playlist item and defines a region of media currently available for playback along with additional information such as whether seeking is supported within the window. The figure below shows some of the information defined by a window, as well as how this information relates to corresponding Periods in the timeline.
