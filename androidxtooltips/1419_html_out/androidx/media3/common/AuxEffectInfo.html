AuxEffectInfo Artifact: androidx.media3:media3-common View Source Kotlin | Java @ UnstableApi public final class AuxEffectInfo Represents auxiliary effect information, which can be used to attach an auxiliary effect to an underlying AudioTrack . Auxiliary effects can only be applied if the application has the android.permission.MODIFY_AUDIO_SETTINGS permission. Apps are responsible for retaining the associated audio effect instance and releasing it when it's no longer needed. See the documentation of AudioEffect for more information.
