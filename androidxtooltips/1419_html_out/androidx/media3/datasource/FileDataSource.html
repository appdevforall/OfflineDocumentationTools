If an IOException is thrown, callers must still call close to ensure that any partial effects of the invocation are cleaned up. The following edge case behaviors apply: If the requested position is within the resource, but the requested length extends beyond the end of the resource, then open will succeed and data from the requested position to the end of the resource will be made available through read . If the requested position is equal to the length of the resource, then open will succeed, and read will immediately return RESULT_END_OF_INPUT . If the requested position is greater than the length of the resource, then open will throw an IOException for which isCausedByPositionOutOfRange will be true .
