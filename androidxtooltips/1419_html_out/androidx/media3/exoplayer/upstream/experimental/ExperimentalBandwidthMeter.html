ExperimentalBandwidthMeter Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class ExperimentalBandwidthMeter implements BandwidthMeter , TransferListener An experimental BandwidthMeter that estimates bandwidth by listening to data transfers. The initial estimate is based on the current operator's network country code or the locale of the user, as well as the network connection type. This can be configured in the Builder .
