DefaultBandwidthMeter Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class DefaultBandwidthMeter implements BandwidthMeter , TransferListener Estimates bandwidth by listening to data transfers. The bandwidth estimate is calculated using a SlidingPercentile and is updated each time a transfer ends. The initial estimate is based on the current operator's network country code or the locale of the user, as well as the network connection type. This can be configured in the Builder .
