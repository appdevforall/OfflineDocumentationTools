Used to obtain keys for decrypting protected media streams. Reference counting Access to an instance is managed by reference counting, where acquire increments the reference count and release decrements it. When the reference count drops to 0 underlying resources are released, and the instance cannot be re-used. Each new instance has an initial reference count of 1. Hence application code that creates a new instance does not normally need to call acquire , and must call release when the instance is no longer required.
