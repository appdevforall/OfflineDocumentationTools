DefaultMediaCodecAdapterFactory Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class DefaultMediaCodecAdapterFactory implements MediaCodecAdapter.Factory The default MediaCodecAdapter.Factory . By default, this factory creates AsynchronousMediaCodecAdapter instances on devices with API level >= 31 (Android 12+). For devices with older API versions, the default behavior is to create SynchronousMediaCodecAdapter instances. The factory offers APIs to force the creation of AsynchronousMediaCodecAdapter (applicable for devices with API >= 23) or SynchronousMediaCodecAdapter instances.
