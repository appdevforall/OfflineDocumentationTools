DefaultAudioSink Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class DefaultAudioSink implements AudioSink Plays audio data. The implementation delegates to an AudioTrack and handles playback position smoothing, non-blocking writes and reconfiguration. If tunneling mode is enabled, care must be taken that audio processors do not output buffers with a different duration than their input, and buffer processors must produce output corresponding to their last input immediately after that input is queued. This means that, for example, speed adjustment is not possible while using tunneling.
