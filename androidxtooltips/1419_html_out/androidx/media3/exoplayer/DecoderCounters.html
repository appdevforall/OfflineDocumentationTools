DecoderCounters Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class DecoderCounters Maintains decoder event counts, for debugging purposes only. Counters should be written from the playback thread only. Counters may be read from any thread. To ensure that the counter values are made visible across threads, users of this class should invoke ensureUpdated prior to reading and after writing.
