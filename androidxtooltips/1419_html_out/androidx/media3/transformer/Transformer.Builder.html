This optimization has the following limitations: Only supported for single-asset (i.e. only one EditedMediaItem in the whole Composition ) exports of mp4 files. This process relies on the given EncoderFactory providing the right encoder level and profiles when transcoding, so that the transcoded and transmuxed segments of the file can be stitched together.
