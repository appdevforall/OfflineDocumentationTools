For export , this should be set for non-image inputs that don't have an intrinsic duration (e.g. raw video data). It will be ignored for inputs that do have an intrinsic duration (e.g. encoded video data from input file). For preview , this should be set for all non-image inputs (i.e. audio and video input). This duration doesn't need to be set for images, because the default value is the 's image duration . If clipping is applied, this should be the duration before clipping.
