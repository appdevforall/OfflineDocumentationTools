Public methods buildAsync public  ListenableFuture < MediaBrowser >  buildAsync () Builds a MediaBrowser asynchronously. The browser instance can be obtained like the following example: MediaBrowser.Builder builder = new MediaBrowser.Builder(context, sessionToken); ListenableFuture<MediaBrowser> future = builder.buildAsync(); future.addListener(() -> { try { MediaBrowser browser = future.get(); // The session accepted the connection. } catch (ExecutionException | InterruptedException e) { if (e.getCause() instanceof SecurityException) { // The session rejected the connection. } } }, ContextCompat.getMainExecutor(context)); The future must be kept by callers until the future is complete to get the controller instance. Otherwise, the future might be garbage collected and the listener added by addListener would never be called.
