EngagementSignalsCallback Artifact: androidx.browser:browser View Source Added in 1.6.0 Kotlin | Java public interface EngagementSignalsCallback A callback class for custom tabs clients to get messages regarding the user's engagement with the webpage within their custom tabs. These methods may not be called for some webpages. In the implementation, all callbacks are sent to the Executor provided by the client or its UI thread if one is not provided.
