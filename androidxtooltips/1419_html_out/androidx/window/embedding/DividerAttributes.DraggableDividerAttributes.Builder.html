If true , the user is allowed to drag beyond the specified range temporarily. When dragging is finished, if the dragging position is below the DragRange.SplitRatioDragRange.minRatio or the default min ratio in DragRange.DRAG_RANGE_SYSTEM_DEFAULT , the system will choose to either fully expand the secondary container or move the divider back to the range limit; if the dragging position is above the DragRange.SplitRatioDragRange.maxRatio or the default max ratio in DragRange.DRAG_RANGE_SYSTEM_DEFAULT , the system will choose to either fully expand the primary container or move the divider back to the range limit. When the primary container is fully expanded, the secondary container is dismissed. When the secondary container is fully expanded, the primary container is hidden behind the secondary container, and the drag handle is displayed on the edge to allow the user to drag and bring back the primary container. Default to false . This is only supported on devices with Window SDK extensions version 7 and above.
