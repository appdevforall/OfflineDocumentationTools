BoundDynamicType Artifact: androidx.wear.protolayout:protolayout-expression-pipeline View Source Added in 1.0.0 Kotlin | Java public interface BoundDynamicType extends AutoCloseable An object representing a dynamic type that is being prepared for evaluation by bind . In order for evaluation and sending values to start, startEvaluation needs to be called. To stop the evaluation, this object should be closed with close . Summary Public methods abstract void @ UiThread close () Destroys this dynamic type and it shouldn't be used after this. abstract void @ UiThread startEvaluation () Starts evaluating this dynamic type that was previously bound with any of the bind methods.
