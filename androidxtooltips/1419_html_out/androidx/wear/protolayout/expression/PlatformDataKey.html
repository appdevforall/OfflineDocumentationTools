The [namespace, key] tuple creates the actual reference, so that a single key can refer to two different sources in two different namespaces. The namespace must not be empty. Additionally, the "protolayout" namespace (and its lowercase and uppercase variations) are reserved for the default platform data sources and should not be used for any custom OEM data source. To make sure namespaces are unique, any custom namespace is expected to follow Java style naming com.company.foo .
