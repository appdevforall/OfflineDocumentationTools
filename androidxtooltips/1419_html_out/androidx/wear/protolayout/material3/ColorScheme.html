ColorScheme Artifact: androidx.wear.protolayout:protolayout-material3 View Source Added in 1.3.0 Kotlin | Java public final class ColorScheme A ColorScheme holds all the named color parameters for a MaterialTheme . Color schemes are designed to be harmonious, ensure accessible text, and distinguish UI elements and surfaces from one another. The Material color system and custom schemes provide default values for color as a starting point for customization. To learn more about color schemes, see Material Design Color System .
