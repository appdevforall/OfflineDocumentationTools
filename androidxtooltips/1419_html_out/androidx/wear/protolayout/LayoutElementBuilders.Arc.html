LayoutElementBuilders.Arc Artifact: androidx.wear.protolayout:protolayout View Source Added in 1.0.0 Kotlin | Java @ RequiresSchemaVersion (major = 1, minor = 0) public final class LayoutElementBuilders.Arc implements LayoutElementBuilders.LayoutElement An arc container. This container will fill itself to a circle, which fits inside its parent container, and all of its children will be placed on that circle. The fields anchor_angle and anchor_type can be used to specify where to draw children within this circle. Note that when setting padding for the arc, if padding values (top, button, left, and right) are not equal, the largest between them will be used to apply padding uniformly to all sides.
