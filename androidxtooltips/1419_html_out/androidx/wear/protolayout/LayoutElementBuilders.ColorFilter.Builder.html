If specified, the image will be tinted, using SRC_IN blending (that is, all color information will be stripped from the target image, and only the alpha channel will be blended with the requested color). Note that only Android image resources can be tinted; Inline images will not be tinted, and this property will have no effect. While this field is statically accessible from 1.0, it's only bindable since version 1.2 and renderers supporting version 1.2 will use the dynamic value (if set).
