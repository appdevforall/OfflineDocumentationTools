WatchFacePushManager.WatchFaceDetails Artifact: androidx.wear.watchfacepush:watchfacepush View Source Added in 1.0.0-alpha01 Kotlin | Java public final class WatchFacePushManager.WatchFaceDetails Details about a watch face that is installed through this API. Once installed, a watch face gets assigned a "slot" that can be then updated with another watch face. Similarly, the watch face in the slot can be deleted, freeing the slot. Each calling app has a limited number of slots that can be utilized.
