ArcLayout.Widget Artifact: androidx.wear:wear View Source Added in 1.2.0 Kotlin | Java public interface ArcLayout.Widget Known direct subclasses CurvedTextView CurvedTextView CurvedTextView is a component allowing developers to easily write curved text following the curvature of the largest circle that can be inscribed in the view. Interface for a widget which knows it is being rendered inside an arc, and will draw itself accordingly. Any widget implementing this interface will receive the full-sized canvas, pre-rotated, in its draw call.
