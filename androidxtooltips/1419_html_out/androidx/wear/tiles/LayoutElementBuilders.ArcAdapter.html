As an example, assume that an Image has been added to the arc, and ends up at the 3 o clock position. If rotate_contents = true, the image will be placed at the 3 o clock position, and will be rotated clockwise through 90 degrees. If rotate_contents = false, the image will be placed at the 3 o clock position, but itself will not be rotated. If not defined, defaults to false. Intended for testing purposes only.
