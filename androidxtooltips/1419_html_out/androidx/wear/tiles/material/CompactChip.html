Use the new class androidx.wear.protolayout.material.CompactChip which provides the same API and functionality. Tiles component CompactChip that represents clickable object with the text. The Chip is Stadium shape and has a max height designed to take no more than one line of text of TYPOGRAPHY_CAPTION1 style. Width of the chip is adjustable to the text size. The recommended set of ChipColors styles can be obtained from ChipDefaults ., e.g. COMPACT_PRIMARY_COLORS to get a color scheme for a primary .
