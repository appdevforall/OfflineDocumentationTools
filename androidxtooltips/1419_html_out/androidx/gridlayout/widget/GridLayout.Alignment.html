GridLayout.Alignment Artifact: androidx.gridlayout:gridlayout View Source Added in 1.0.0 Kotlin | Java public abstract class GridLayout.Alignment Alignments specify where a view should be placed within a cell group and what size it should be. The LayoutParams class contains a rowSpec and a columnSpec each of which contains an alignment . Overall placement of the view in the cell group is specified by the two alignments which act along each axis independently. The GridLayout class defines the most common alignments used in general layout: TOP , LEFT , BOTTOM , RIGHT , START , END , CENTER , BASELINE and FILL .
