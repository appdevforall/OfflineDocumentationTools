Public methods onViewRecycled Added in 1.0.0 abstract void  onViewRecycled (@ NonNull RecyclerView.ViewHolder  holder) This method is called whenever the view in the ViewHolder is recycled. RecyclerView calls this method right before clearing ViewHolder's internal data and sending it to RecycledViewPool. This way, if ViewHolder was holding valid information before being recycled, you can call getBindingAdapterPosition to get its adapter position.
