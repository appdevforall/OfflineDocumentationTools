RecyclerView.ItemAnimator.ItemHolderInfo Artifact: androidx.recyclerview:recyclerview View Source Added in 1.0.0 Kotlin | Java public class RecyclerView.ItemAnimator.ItemHolderInfo A simple data structure that holds information about an item's bounds. This information is used in calculating item animations. Default implementation of recordPreLayoutInformation and recordPostLayoutInformation returns this data structure. You can extend this class if you would like to keep more information about the Views. If you want to provide your own implementation but still use `super` methods to record basic information, you can override obtainHolderInfo to provide your own instances.
