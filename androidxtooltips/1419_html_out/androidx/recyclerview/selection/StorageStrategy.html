StorageStrategy Artifact: androidx.recyclerview:recyclerview-selection View Source Added in 1.0.0 Kotlin | Java public abstract class StorageStrategy <K> Strategy for storing keys in saved state. Extend this class when using custom key types that aren't supported by default. Prefer use of builtin storage strategies: createStringStorage , createLongStorage , createParcelableStorage . See SelectionTracker.Builder for more detailed advice on which key type to use for your selection keys. Parameters <K> Selection key type. Built in support is provided for String, Long, and Parcelable types.
