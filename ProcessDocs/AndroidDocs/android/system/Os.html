Os Kotlin | Java public final class Os extends Object java.lang.Object ↳ android.system.Os Access to low-level system functionality. Most of these are system calls. Most users will want to use higher-level APIs where available, but this class provides access to the underlying primitives used to implement the higher-level APIs. The corresponding constants can be found in OsConstants .
