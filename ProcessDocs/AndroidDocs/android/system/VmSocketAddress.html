VmSocketAddress corresponds to struct sockaddr_vm in bionic/libc/kernel/uapi/linux/vm_sockets.h. Currently virtio-vsock is used as a generic purpose pipe in emulators to talk to the host. Most I/O operations using this address via Os class will require additional permissions to talk to the host.
