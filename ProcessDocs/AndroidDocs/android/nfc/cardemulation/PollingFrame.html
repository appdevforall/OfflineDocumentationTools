PollingFrame Kotlin | Java public final class PollingFrame extends Object implements Parcelable java.lang.Object ↳ android.nfc.cardemulation.PollingFrame Polling Frames represent data about individual frames of an NFC polling loop. These frames will be delivered to subclasses of HostApduService that have registered filters with CardEmulation.registerPollingLoopFilterForService(ComponentName, String, boolean) that match a given frame in a loop and will be delivered through calls to HostApduService.processPollingFrames(List) .
