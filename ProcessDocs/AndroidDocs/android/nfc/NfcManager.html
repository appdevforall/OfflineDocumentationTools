NfcManager Kotlin | Java public final class NfcManager extends Object java.lang.Object ↳ android.nfc.NfcManager High level manager used to obtain an instance of an NfcAdapter . Use Context.getSystemService(java.lang.String) with Context.NFC_SERVICE to create an NfcManager , then call getDefaultAdapter() to obtain the NfcAdapter . Alternately, you can just call the static helper NfcAdapter.getDefaultAdapter(android.content.Context) .
