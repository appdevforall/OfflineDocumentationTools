Sampler object that defines how Allocations can be read as textures within a kernel. Samplers are used in conjunction with the rsSample runtime function to return values from normalized coordinates. Any Allocation used with a Sampler must have been created with Allocation.USAGE_GRAPHICS_TEXTURE ; using a Sampler on an Allocation that was not created with Allocation.USAGE_GRAPHICS_TEXTURE is undefined.
