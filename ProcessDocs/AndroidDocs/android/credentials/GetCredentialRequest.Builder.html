Throws IllegalArgumentException If credentialOptions is empty. setAlwaysSendAppInfoToProvider Added in API level 34 public GetCredentialRequest.Builder setAlwaysSendAppInfoToProvider (boolean value) Sets a true/false value to determine if the calling app info should be removed from the request that is sent to the providers. Developers must set this to false if they wish to remove the CallingAppInfo from the query phases requests that providers receive. Note that the calling app info will still be sent in the final phase after the user has made a selection on the UI. If not set, the default value will be true and the calling app info will be propagated to the providers in every phase.
