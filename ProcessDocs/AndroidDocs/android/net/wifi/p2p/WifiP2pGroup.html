WifiP2pGroup Kotlin | Java public class WifiP2pGroup extends Object implements Parcelable java.lang.Object ↳ android.net.wifi.p2p.WifiP2pGroup A class representing a Wi-Fi P2p group. A p2p group consists of a single group owner and one or more clients. In the case of a group with only two devices, one will be the group owner and the other will be a group client.
