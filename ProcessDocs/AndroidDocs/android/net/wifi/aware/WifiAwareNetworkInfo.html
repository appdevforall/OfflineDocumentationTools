WifiAwareNetworkInfo Kotlin | Java public final class WifiAwareNetworkInfo extends Object implements Parcelable , TransportInfo java.lang.Object ↳ android.net.wifi.aware.WifiAwareNetworkInfo Wi-Fi Aware-specific network information. The information can be extracted from the NetworkCapabilities of the network using NetworkCapabilities.getTransportInfo() . The NetworkCapabilities is provided by the connectivity service to apps, e.g. received through the ConnectivityManager.NetworkCallback.onCapabilitiesChanged(android.net.Network, android.net.NetworkCapabilities) callback. The Wi-Fi Aware-specific network information include the peer's scoped link-local IPv6 address for the Wi-Fi Aware link, as well as (optionally) the port and transport protocol specified by the peer. The scoped link-local IPv6, port, and transport protocol can then be used to create a Socket connection to the peer. Note: these are the peer's IPv6 and port information - not the local device's!
