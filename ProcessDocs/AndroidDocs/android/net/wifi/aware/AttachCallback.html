AttachCallback Kotlin | Java public class AttachCallback extends Object java.lang.Object ↳ android.net.wifi.aware.AttachCallback Base class for Aware attach callbacks. Should be extended by applications and set when calling WifiAwareManager.attach(AttachCallback, android.os.Handler) . These are callbacks applying to the Aware connection as a whole - not to specific publish or subscribe sessions - for that see DiscoverySessionCallback .
