DiscoverySessionCallback Kotlin | Java public class DiscoverySessionCallback extends Object java.lang.Object ↳ android.net.wifi.aware.DiscoverySessionCallback Base class for Aware session events callbacks. Should be extended by applications wanting notifications. The callbacks are set when a publish or subscribe session is created using WifiAwareSession.publish(PublishConfig, DiscoverySessionCallback, android.os.Handler) or WifiAwareSession.subscribe(SubscribeConfig, DiscoverySessionCallback, android.os.Handler) . A single callback is set at session creation - it cannot be replaced.
