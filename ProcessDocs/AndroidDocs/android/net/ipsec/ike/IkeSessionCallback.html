IkeSessionCallback Kotlin | Java public interface IkeSessionCallback android.net.ipsec.ike.IkeSessionCallback Callback interface for receiving state changes of an IkeSession . IkeSessionCallback MUST be unique to each IkeSession . It is registered when callers are requesting a new IkeSession . It is automatically unregistered when an IkeSession is closed.
