IkeSession Kotlin | Java public final class IkeSession extends Object implements AutoCloseable java.lang.Object ↳ android.net.ipsec.ike.IkeSession This class represents an IKE Session management object that allows for keying and management of IpSecTransform s. An IKE/Child Session represents an IKE/Child SA as well as its rekeyed successors. A Child Session is bounded by the lifecycle of the IKE Session under which it is set up. Closing an IKE Session implicitly closes any remaining Child Sessions under it. An IKE procedure is one or multiple IKE message exchanges that are used to create, delete or rekey an IKE Session or Child Session. This class provides methods for initiating IKE procedures, such as the Creation and Deletion of a Child Session, or the Deletion of the IKE session. All procedures (except for IKE deletion) will be initiated sequentially after IKE Session is set up.
