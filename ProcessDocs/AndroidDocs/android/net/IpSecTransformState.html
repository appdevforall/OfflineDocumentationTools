IpSecTransformState Kotlin | Java public final class IpSecTransformState extends Object implements Parcelable java.lang.Object ↳ android.net.IpSecTransformState This class represents a snapshot of the state of an IpSecTransform This class provides the current state of an IpSecTransform, enabling link metric analysis by the caller. Use cases include understanding transform usage, such as packet and byte counts, as well as observing out-of-order delivery by checking the bitmap. Additionally, callers can query IpSecTransformStates at two timestamps. By comparing the changes in packet counts and sequence numbers, callers can estimate IPsec data loss in the inbound direction.
