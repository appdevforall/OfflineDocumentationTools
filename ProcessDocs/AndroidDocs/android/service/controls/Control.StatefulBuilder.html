Control.StatefulBuilder Kotlin | Java public static final class Control.StatefulBuilder extends Object java.lang.Object ↳ android.service.controls.Control.StatefulBuilder Builder class for Control that contains state information. State information is passed through an instance of a ControlTemplate and will determine how the user can interact with the Control . User interactions will be sent through the method call ControlsProviderService.performControlAction with an instance of ControlAction to convey any potential new value. Must be used to provide controls for ControlsProviderService.createPublisherFor .
