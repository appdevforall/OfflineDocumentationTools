TemperatureControlTemplate Kotlin | Java public final class TemperatureControlTemplate extends ControlTemplate java.lang.Object ↳ android.service.controls.templates.ControlTemplate ↳ android.service.controls.templates.TemperatureControlTemplate A template for a temperature related Control that supports multiple modes. Both the current mode and the active mode for the control can be specified. The combination of the Control.getDeviceType and the current and active mode will determine colors and transitions for the UI element.
