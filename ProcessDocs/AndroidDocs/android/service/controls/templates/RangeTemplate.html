Public constructors RangeTemplate Added in API level 30 public RangeTemplate ( String templateId, float minValue, float maxValue, float currentValue, float stepValue, CharSequence formatString) Construct a new RangeTemplate . The range must be valid, meaning: minValue < maxValue minValue < currentValue currentValue < maxValue 0 < stepValue The current value of the Control will be formatted accordingly. Parameters templateId String : the identifier for this template object This value cannot be null . minValue float : minimum value for the input maxValue float : maximum value for the input currentValue float : the current value of the Control containing this object. stepValue float : minimum value of increments/decrements when interacting with this control. formatString CharSequence : a formatting string as per String.format used to display the currentValue . If null is passed, the "%.1f" is used. Throws IllegalArgumentException if the parameters passed do not make a valid range.
