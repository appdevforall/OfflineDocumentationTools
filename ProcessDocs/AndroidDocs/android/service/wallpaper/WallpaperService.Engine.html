WallpaperService.Engine Kotlin | Java public class WallpaperService.Engine extends Object java.lang.Object ↳ android.service.wallpaper.WallpaperService.Engine The actual implementation of a wallpaper. A wallpaper service may have multiple instances running (for example as a real wallpaper and as a preview), each of which is represented by its own Engine instance. You must implement WallpaperService.onCreateEngine() to return your concrete Engine implementation.
