Sanitizer Kotlin | Java public interface Sanitizer android.service.autofill.Sanitizer Known indirect subclasses DateValueSanitizer , TextValueSanitizer DateValueSanitizer Sanitizes a date AutofillValue using a DateFormat . TextValueSanitizer Sanitizes a text AutofillValue using a regular expression (regex) substitution. Helper class used to sanitize user input before using it in a save request. Typically used to avoid displaying the save UI for values that are autofilled but reformatted by the app—for example, if the autofill service sends a credit card number value as "004815162342108" and the app automatically changes it to "0048 1516 2342 108". Note: This interface is not meant to be implemented by app developers; only implementations provided by the Android System can be used in other Autofill APIs.
