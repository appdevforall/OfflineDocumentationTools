Each of the methods that takes one of these to send the result must call sendResult(T) to respond to the caller with the given results. If those functions return without calling sendResult(T) , they must instead call detach() before returning, and then may call sendResult(T) when they are done. If more than one of those methods is called, an exception will be thrown.
