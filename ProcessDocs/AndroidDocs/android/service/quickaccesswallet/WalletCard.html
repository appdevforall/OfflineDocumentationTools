WalletCard Kotlin | Java public final class WalletCard extends Object implements Parcelable java.lang.Object ↳ android.service.quickaccesswallet.WalletCard A WalletCard can represent anything that a user might carry in their wallet -- a credit card, library card, transit pass, etc. Cards are identified by a String identifier and contain a card type, card image, card image content description, and a PendingIntent to be used if the user clicks on the card. Cards may be displayed with an icon and label, though these are optional. Non-payment cards will also have a second image that will be displayed when the card is tapped.
