It's mainly used by platform. If OutputSpec is set to OutputSpec.DEFAULT , OnDevicePersonalization will ignore result returned by IsolatedService . If OutputSpec is built with buildBestValueSpec(int) , OnDevicePersonalization will verify ExecuteOutput.getBestValue() returned by IsolatedService within the max value range set in OutputSpec.getMaxIntValue and add noise.
