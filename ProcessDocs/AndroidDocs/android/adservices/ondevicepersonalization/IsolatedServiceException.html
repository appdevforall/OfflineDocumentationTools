IsolatedServiceException Kotlin | Java public final class IsolatedServiceException extends Exception java.lang.Object ↳ java.lang.Throwable ↳ java.lang.Exception ↳ android.adservices.ondevicepersonalization.IsolatedServiceException A class that an IsolatedService can use to signal a failure in handling a request and return an error to be logged and aggregated. The error is not reported to the app that invoked the IsolatedService in order to prevent data leakage from the IsolatedService to an app. The platform does not interpret the error code, it only logs and aggregates it.
