EventUrlProvider Kotlin | Java public class EventUrlProvider extends Object java.lang.Object ↳ android.adservices.ondevicepersonalization.EventUrlProvider Generates event tracking URLs for a request. The service can embed these URLs within the HTML output as needed. When the HTML is rendered within an ODP WebView, ODP will intercept requests to these URLs, call IsolatedWorker#onEvent(EventInput, android.os.OutcomeReceiver) , and log the returned output in the EVENTS table.
