FrequencyCapFilters Kotlin | Java public final class FrequencyCapFilters extends Object implements Parcelable java.lang.Object ↳ android.adservices.common.FrequencyCapFilters A container for the ad filters that are based on frequency caps. No more than 20 frequency cap filters may be associated with a single ad. Frequency caps filters combine an event type with a list of KeyedFrequencyCap objects to define a collection of ad filters. If any of these frequency caps are exceeded for a given ad, the ad will be removed from the group of ads submitted to a buyer adtech's bidding function.
