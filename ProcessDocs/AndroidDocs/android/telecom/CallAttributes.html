CallAttributes Kotlin | Java public final class CallAttributes extends Object implements Parcelable java.lang.Object ↳ android.telecom.CallAttributes CallAttributes represents a set of properties that define a new Call. Apps should build an instance of this class and use TelecomManager.addCall to start a new call with Telecom. Apps should first register a PhoneAccount via TelecomManager.registerPhoneAccount and use the same PhoneAccountHandle registered with Telecom when creating an instance of CallAttributes.
