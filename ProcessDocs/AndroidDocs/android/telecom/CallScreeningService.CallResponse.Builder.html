Attachments that are not shown will not be passed to the in-call UI responsible for displaying the call to the user. If this method is not called on a Builder , all attachments will be shown, except pictures, which will only be shown to users if the call is from a contact. Setting attachments to show will have no effect if the call screening service does not belong to the same package as the system dialer (as returned by TelecomManager.getSystemDialerPackage() ). Parameters callComposerAttachmentsToShow int : A bitmask of call composer attachments to show. When set to true , the Telecom framework will not play a ringtone for the call. The call will, however, still be sent to the default dialer app if it is not blocked. A CallScreeningService can use this to ensure a potential nuisance call is still surfaced to the user, but in a less intrusive manner. Setting this to true only makes sense when the call has not been disallowed using setDisallowCall(boolean) .
