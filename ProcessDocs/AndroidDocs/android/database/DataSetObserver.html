DataSetObserver Kotlin | Java public abstract class DataSetObserver extends Object java.lang.Object ↳ android.database.DataSetObserver Known direct subclasses AlphabetIndexer AlphabetIndexer A helper class for adapters that implement the SectionIndexer interface. Receives call backs when a data set has been changed, or made invalid. The typically data sets that are observed are Cursor s or Adapter s. DataSetObserver must be implemented by objects which are added to a DataSetObservable.
