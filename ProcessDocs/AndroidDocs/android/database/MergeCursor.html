MergeCursor Kotlin | Java public class MergeCursor extends AbstractCursor java.lang.Object ↳ android.database.AbstractCursor ↳ android.database.MergeCursor A convenience class that lets you present an array of Cursors as a single linear Cursor. The schema of the cursors presented is entirely up to the creator of the MergeCursor, and may be different if that is desired. Calls to getColumns, getColumnIndex, etc will return the value for the row that the MergeCursor is currently pointing at.
