Note that the pipe is blocking, so this thread can block on writes for an arbitrary amount of time if the client is slow at reading. Parameters output ParcelFileDescriptor : The pipe where data should be written. This will be closed for you upon returning from this function. This value cannot be null . uri Uri : The URI whose data is to be written. This value cannot be null . mimeType String : The desired type of data to be written.
