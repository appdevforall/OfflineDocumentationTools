Class for retrieving various kinds of information related to the application packages that are currently installed on the device. You can find this class through Context.getPackageManager . Note: If your app targets Android 11 (API level 30) or higher, the methods in this class each return a filtered list of apps. Learn more about how to manage package visibility .
