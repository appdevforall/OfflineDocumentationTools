DialogInterface.OnKeyListener Kotlin | Java public static interface DialogInterface.OnKeyListener android.content.DialogInterface.OnKeyListener Interface definition for a callback to be invoked when a key event is dispatched to this dialog. The callback will be invoked before the key event is given to the dialog.
