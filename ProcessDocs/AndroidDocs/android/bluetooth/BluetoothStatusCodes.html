BluetoothStatusCodes Kotlin | Java public final class BluetoothStatusCodes extends Object java.lang.Object ↳ android.bluetooth.BluetoothStatusCodes A class with constants representing possible return values for Bluetooth APIs. General return values occupy the range 0 to 199. Profile-specific return values occupy the range 200-999. API-specific return values start at 1000. The exception to this is the "UNKNOWN" error code which occupies the max integer value.
