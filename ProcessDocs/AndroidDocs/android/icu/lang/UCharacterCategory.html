UCharacterCategory Kotlin | Java public final class UCharacterCategory extends Object implements UCharacterEnums.ECharacterCategory java.lang.Object ↳ android.icu.lang.UCharacterCategory Enumerated Unicode category types from the UnicodeData.txt file. Used as return results from UCharacter Equivalent to icu's UCharCategory. Refer to Unicode Consortium for more information about UnicodeData.txt. NOTE: the UCharacterCategory values are not compatible with those returned by java.lang.Character.getType. UCharacterCategory values match the ones used in ICU4C, while java.lang.Character type values, though similar, skip the value 17.
