UProperty.NameChoice Kotlin | Java public static interface UProperty.NameChoice android.icu.lang.UProperty.NameChoice Selector constants for UCharacter.getPropertyName() and UCharacter.getPropertyValueName(). These selectors are used to choose which name is returned for a given property or value. All properties and values have a long name. Most have a short name, but some do not. Unicode allows for additional names, beyond the long and short name, which would be indicated by LONG + i, where i=1, 2,...
