Enum values ANY_BASE_WEIGHT_IS_WILDCARD Added in API level 24 public static final SearchIterator.ElementComparisonType ANY_BASE_WEIGHT_IS_WILDCARD Collation element comparison is modified to effectively provide behavior between the specified strength and strength - 1. Collation elements in either the pattern or the searched text that have the base weight for the specified strength are treated as "wildcards" that match an element with any other weight at that collation level. For example, with a secondary-strength English collator, a plain 'e' in the pattern will match a plain e or an e with any diacritic in the searched text, but an e with diacritic in the pattern will only match an e with the same diacritic or a plain e in the searched text.
