Enum values MIN_ELEMENTS Added in API level 24 public static final UnicodeSetSpanner.CountMethod MIN_ELEMENTS Use the smallest number of elements in the spanned range for counting and modification, based on the UnicodeSet.SpanCondition . If the set has no strings, this will be the same as the number of spanned code points. For example, in the string "abab" with SpanCondition.SIMPLE: spanning with [ab] will count four MIN_ELEMENTS. spanning with [{ab}] will count two MIN_ELEMENTS. spanning with [ab{ab}] will also count two MIN_ELEMENTS.
