BidiRun Kotlin | Java public class BidiRun extends Object java.lang.Object ↳ android.icu.text.BidiRun A BidiRun represents a sequence of characters at the same embedding level. The Bidi algorithm decomposes a piece of text into sequences of characters at the same embedding level, each such sequence is called a "run". A BidiRun represents such a run by storing its essential properties, but does not duplicate the characters which form the run. The "limit" of the run is the position just after the last character, i.e., one more than that position. This class has no public constructor, and its members cannot be modified by users.
