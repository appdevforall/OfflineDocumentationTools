NumberingSystem Kotlin | Java public class NumberingSystem extends Object java.lang.Object ↳ android.icu.text.NumberingSystem NumberingSystem is the base class for all number systems. This class provides the interface for setting different numbering system types, whether it be a simple alternate digit system such as Thai digits or Devanagari digits, or an algorithmic numbering system such as Hebrew numbering or Chinese numbering.
