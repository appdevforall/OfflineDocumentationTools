Enum values DOUBLE_OPTIONAL Added in API level 24 public static final MessagePattern.ApostropheMode DOUBLE_OPTIONAL A literal apostrophe is represented by either a single or a double apostrophe pattern character. Within a MessageFormat pattern, a single apostrophe only starts quoted literal text if it immediately precedes a curly brace {}, or a pipe symbol | if inside a choice format, or a pound symbol # if inside a plural format. This is the default behavior starting with ICU 4.8. DOUBLE_REQUIRED Added in API level 24 public static final MessagePattern.ApostropheMode DOUBLE_REQUIRED A literal apostrophe must be represented by a double apostrophe pattern character. A single apostrophe always starts quoted literal text. This is the behavior of ICU 4.6 and earlier, and of MessageFormat .
