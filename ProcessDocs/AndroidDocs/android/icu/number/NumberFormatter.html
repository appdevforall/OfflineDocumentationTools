NumberFormatter instances (i.e., LocalizedNumberFormatter and UnlocalizedNumberFormatter) are immutable and thread safe. This means that invoking a configuration method has no effect on the receiving instance; you must store and use the new number formatter instance it returns instead. UnlocalizedNumberFormatter formatter = UnlocalizedNumberFormatter.with() .notation(Notation.scientific()); formatter.precision(Precision.maxFraction(2)); // does nothing! formatter.locale(ULocale.ENGLISH).format(9.8765).toString(); // prints "9.8765E0", not "9.88E0" This API is based on the fluent design pattern popularized by libraries such as Google's Guava.
