Public methods withCurrency Added in API level 30 public Precision withCurrency ( Currency currency) Associates a currency with this rounding strategy. Calling this method is not required , because the currency specified in unit() or via a CurrencyAmount passed into format(Measure) is automatically applied to currency rounding strategies. However, this method enables you to override that automatic association. This method also enables numbers to be formatted using currency rounding rules without explicitly using a currency format. Parameters currency Currency : The currency to associate with this rounding strategy. Returns Precision A Precision for chaining or passing to the NumberFormatter rounding() setter.
