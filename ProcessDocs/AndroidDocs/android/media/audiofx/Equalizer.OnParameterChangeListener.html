Public methods onParameterChange Added in API level 9 public abstract void onParameterChange ( Equalizer effect, int status, int param1, int param2, int value) Method called when a parameter value has changed. The method is called only if the parameter was changed by another application having the control of the same Equalizer engine. Parameters effect Equalizer : the Equalizer on which the interface is registered. status int : status of the set parameter operation. param1 int : ID of the modified parameter. See Equalizer.PARAM_BAND_LEVEL ... param2 int : additional parameter qualifier (e.g the band for band level parameter). value int : the new parameter value.
