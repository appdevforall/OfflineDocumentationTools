Public methods onParameterChange Added in API level 9 public abstract void onParameterChange ( PresetReverb effect, int status, int param, short value) Method called when a parameter value has changed. The method is called only if the parameter was changed by another application having the control of the same PresetReverb engine. Parameters effect PresetReverb : the PresetReverb on which the interface is registered. status int : status of the set parameter operation. param int : ID of the modified parameter. See PresetReverb.PARAM_PRESET ... value short : the new parameter value.
