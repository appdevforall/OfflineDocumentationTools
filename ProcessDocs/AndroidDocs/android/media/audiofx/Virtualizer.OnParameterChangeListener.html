Public methods onParameterChange Added in API level 9 public abstract void onParameterChange ( Virtualizer effect, int status, int param, short value) Method called when a parameter value has changed. The method is called only if the parameter was changed by another application having the control of the same Virtualizer engine. Parameters effect Virtualizer : the Virtualizer on which the interface is registered. status int : status of the set parameter operation. param int : ID of the modified parameter. See Virtualizer.PARAM_STRENGTH ... value short : the new parameter value.
