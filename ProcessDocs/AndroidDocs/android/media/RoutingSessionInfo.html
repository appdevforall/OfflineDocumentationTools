Returns int Value is TRANSFER_REASON_FALLBACK , TRANSFER_REASON_SYSTEM_REQUEST , or TRANSFER_REASON_APP getTransferableRoutes Added in API level 30 public List < String > getTransferableRoutes () Gets the list of IDs of transferable routes for the session. Transferring to a route (for example, using MediaRouter2.transferTo ) replaces the list of selected routes with the target route, causing playback to move from one route to another. Note that this is different from selectable routes , because selecting a route makes it part of the selected routes, while transferring to a route makes it the selected route. A route can be both transferable and selectable. Note that playback may transfer across routes without the target route being in the list of transferable routes. This can happen by creating a new routing session to the target route, and releasing the routing session being transferred from. The difference is that a transfer to a route in the transferable list can happen with no intervention from the app, with the route provider taking care of the entire operation. A transfer to a route that is not in the list of transferable routes (by creating a new session) requires the app to move the playback state from one device to the other.
