VolumeProvider Kotlin | Java public abstract class VolumeProvider extends Object java.lang.Object ↳ android.media.VolumeProvider Handles requests to adjust or set the volume on a session. This is also used to push volume updates back to the session. The provider must call setCurrentVolume(int) each time the volume being provided changes. You can set a volume provider on a session by calling MediaSession.setPlaybackToRemote .
