RemoteController.MetadataEditor A class to read the metadata published by a RemoteControlClient , or send a RemoteControlClient new values for keys that can be edited. This class was deprecated in API level 21. Use MediaMetadata instead together with MediaSession . An abstract class for editing and storing metadata that can be published by RemoteControlClient . See the RemoteControlClient.editMetadata(boolean) method to instantiate a RemoteControlClient.MetadataEditor object.
