TvContract.Channels.Logo Kotlin | Java public static final class TvContract.Channels.Logo extends Object java.lang.Object ↳ android.media.tv.TvContract.Channels.Logo A sub-directory of a single TV channel that represents its primary logo. To access this directory, append CONTENT_DIRECTORY to the raw channel URI. The resulting URI represents an image file, and should be interacted using ContentResolver.openAssetFileDescriptor. Note that this sub-directory also supports opening the logo as an asset file in write mode. Callers can create or replace the primary logo associated with this channel by opening the asset file and writing the full-size photo contents into it. (Make sure there is no padding around the logo image.) When the file is closed, the image will be parsed, sized down if necessary, and stored.
