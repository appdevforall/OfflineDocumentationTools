TvContract Kotlin | Java public final class TvContract extends Object java.lang.Object ↳ android.media.tv.TvContract The contract between the TV provider and applications. Contains definitions for the supported URIs and columns. Overview TvContract defines a basic database of TV content metadata such as channel and program information. The information is stored in Channels and Programs tables. A row in the Channels table represents information about a TV channel. The data format can vary greatly from standard to standard or according to service provider, thus the columns here are mostly comprised of basic entities that are usually seen to users regardless of standard such as channel number and name. A row in the Programs table represents a set of data describing a TV program such as program title and start time.
