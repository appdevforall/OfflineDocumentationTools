EffectContext Kotlin | Java public class EffectContext extends Object java.lang.Object ↳ android.media.effect.EffectContext An EffectContext keeps all necessary state information to run Effects within a Open GL ES 2.0 context. Every EffectContext is bound to one GL context. The application is responsible for creating this EGL context, and making it current before applying any effect. If your EGL context is destroyed, the EffectContext becomes invalid and any effects bound to this context can no longer be used. If you switch to another EGL context, you must create a new EffectContext. Each Effect is bound to a single EffectContext, and can only be executed in that context.
