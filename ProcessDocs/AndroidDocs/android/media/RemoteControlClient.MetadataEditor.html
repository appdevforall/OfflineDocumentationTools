Use MediaMetadata and MediaSession instead. Class used to modify metadata in a RemoteControlClient object. Use RemoteControlClient.editMetadata(boolean) to create an instance of an editor, on which you set the metadata for the RemoteControlClient instance. Once all the information has been set, use apply() to make it the new metadata that should be displayed for the associated client. Once the metadata has been "applied", you cannot reuse this instance of the MetadataEditor. Summary Constants int BITMAP_KEY_ARTWORK The metadata key for the content artwork / album art.
