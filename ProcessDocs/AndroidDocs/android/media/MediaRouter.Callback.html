Interface for receiving events about media routing changes. All methods of this interface will be called from the application's main thread. A Callback will only receive events relevant to routes that the callback was registered for unless the MediaRouter.CALLBACK_FLAG_UNFILTERED_EVENTS flag was specified in MediaRouter.addCallback(int, Callback, int) .
