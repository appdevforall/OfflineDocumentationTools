Return allowed commands for controller. By default it returns null . You can reject the connection by returning null . In that case, controller receives MediaController2.ControllerCallback.onDisconnected(MediaController2) and cannot be used. The controller hasn't connected yet in this method, so calls to the controller (e.g. MediaSession2.sendSessionCommand(ControllerInfo, Session2Command, Bundle) ) would be ignored. Override onPostConnect(MediaSession2, ControllerInfo) for the custom initialization for the controller instead.
