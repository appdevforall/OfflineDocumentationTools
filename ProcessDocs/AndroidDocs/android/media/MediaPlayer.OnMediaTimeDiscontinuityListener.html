MediaPlayer.OnMediaTimeDiscontinuityListener Kotlin | Java public static interface MediaPlayer.OnMediaTimeDiscontinuityListener android.media.MediaPlayer.OnMediaTimeDiscontinuityListener Interface definition of a callback to be invoked when discontinuity in the normal progression of the media time is detected. The "normal progression" of media time is defined as the expected increase of the playback position when playing media, relative to the playback speed (for instance every second, media time increases by two seconds when playing at 2x). Discontinuities are encountered in the following cases: when the player is starved for data and cannot play anymore when the player encounters a playback error when the a seek operation starts, and when it's completed when the playback speed changes when the playback state changes when the player is reset See the MediaPlayer.setOnMediaTimeDiscontinuityListener(OnMediaTimeDiscontinuityListener, Handler) method to set a listener for these events.
