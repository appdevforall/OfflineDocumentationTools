Represents the basic Preference UI building block displayed by a PreferenceActivity in the form of a ListView . This class provides the View to be displayed in the activity and associates with a SharedPreferences to store/retrieve the preference data. When specifying a preference hierarchy in XML, each element can point to a subclass of Preference , similar to the view hierarchy and layouts. This class contains a key that will be used as the key into the SharedPreferences . It is up to the subclass to decide how to store the value. Developer Guides For information about building a settings UI with Preferences, read the Settings guide.
