The general contract of hashCode is: Whenever it is invoked on the same object more than once during an execution of a Java application, the hashCode method must consistently return the same integer, provided no information used in equals comparisons on the object is modified. This integer need not remain consistent from one execution of an application to another execution of the same application. However, the programmer should be aware that producing distinct integer results for unequal objects may improve the performance of hash tables. The ASCII characters \ u002a ('*') and \ u0078 ('x') are recognized as separators between the width and height. For any SizeF s : SizeF.parseSizeF(s.toString()).equals(s) .
