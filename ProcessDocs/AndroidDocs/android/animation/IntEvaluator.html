Public constructors IntEvaluator public IntEvaluator () Public methods evaluate Added in API level 14 public Integer evaluate (float fraction, Integer startValue, Integer endValue) This function returns the result of linearly interpolating the start and end values, with fraction representing the proportion between the start and end values. The calculation is a simple parametric calculation: result = x0 + t * (x1 - x0) , where x0 is startValue , x1 is endValue , and t is fraction .
