Public methods evaluate Added in API level 11 public abstract T evaluate (float fraction, T startValue, T endValue) This function returns the result of linearly interpolating the start and end values, with fraction representing the proportion between the start and end values. The calculation is a simple parametric calculation: result = x0 + t * (x1 - x0) , where x0 is startValue , x1 is endValue , and t is fraction . Parameters fraction float : The fraction from the starting to the ending values startValue T : The start value. endValue T : The end value. Returns T A linear interpolation between the start and end values, given the fraction parameter.
