Public constructors FloatEvaluator public FloatEvaluator () Public methods evaluate Added in API level 14 public Float evaluate (float fraction, Number startValue, Number endValue) This function returns the result of linearly interpolating the start and end values, with fraction representing the proportion between the start and end values. The calculation is a simple parametric calculation: result = x0 + t * (x1 - x0) , where x0 is startValue , x1 is endValue , and t is fraction .
