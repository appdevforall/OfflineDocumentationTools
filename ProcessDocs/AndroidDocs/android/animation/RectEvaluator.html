Public methods evaluate Added in API level 18 public Rect evaluate (float fraction, Rect startValue, Rect endValue) This function returns the result of linearly interpolating the start and end Rect values, with fraction representing the proportion between the start and end values. The calculation is a simple parametric calculation on each of the separate components in the Rect objects (left, top, right, and bottom). If RectEvaluator(android.graphics.Rect) was used to construct this RectEvaluator, the object returned will be the reuseRect passed into the constructor.
