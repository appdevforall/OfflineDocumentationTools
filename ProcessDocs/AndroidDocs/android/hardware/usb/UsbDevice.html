UsbDevice Kotlin | Java public class UsbDevice extends Object implements Parcelable java.lang.Object ↳ android.hardware.usb.UsbDevice This class represents a USB device attached to the android device with the android device acting as the USB host. Each device contains one or more UsbInterface s, each of which contains a number of UsbEndpoint s (the channels via which data is transmitted over USB). This class contains information (along with UsbInterface and UsbEndpoint ) that describes the capabilities of the USB device. To communicate with the device, you open a UsbDeviceConnection for the device and use UsbRequest to send and receive data on an endpoint. UsbDeviceConnection.controlTransfer is used for control requests on endpoint zero. Developer Guides For more information about communicating with USB hardware, read the USB developer guide.
