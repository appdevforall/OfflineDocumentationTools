UsbEndpoint Kotlin | Java public class UsbEndpoint extends Object implements Parcelable java.lang.Object ↳ android.hardware.usb.UsbEndpoint A class representing an endpoint on a UsbInterface . Endpoints are the channels for sending and receiving data over USB. Typically bulk endpoints are used for sending non-trivial amounts of data. Interrupt endpoints are used for sending small amounts of data, typically events, separately from the main data streams. The endpoint zero is a special endpoint for control messages sent from the host to device. Isochronous endpoints are currently unsupported.
