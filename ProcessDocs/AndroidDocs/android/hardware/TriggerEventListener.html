TriggerEventListener Kotlin | Java public abstract class TriggerEventListener extends Object java.lang.Object ↳ android.hardware.TriggerEventListener This class is the listener used to handle Trigger Sensors. Trigger Sensors are sensors that trigger an event and are automatically disabled. Sensor.TYPE_SIGNIFICANT_MOTION is one such example. SensorManager lets you access the device's sensors . Get an instance of SensorManager by calling Context.getSystemService() with the argument Context.SENSOR_SERVICE .
