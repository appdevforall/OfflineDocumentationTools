VirtualDisplay Kotlin | Java public final class VirtualDisplay extends Object java.lang.Object ↳ android.hardware.display.VirtualDisplay Represents a virtual display. The content of a virtual display is rendered to a Surface that you must provide to createVirtualDisplay() . Because a virtual display renders to a surface provided by the application, it will be released automatically when the process terminates and all remaining windows on it will be forcibly removed. However, you should also explicitly call release() when you're done with it.
