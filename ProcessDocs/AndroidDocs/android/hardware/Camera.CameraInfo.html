On some devices, the camera shutter sound cannot be turned off through enableShutterSound . This field can be used to determine whether a call to disable the shutter sound will succeed. If this field is set to true, then a call of enableShutterSound(false) will be successful. If set to false, then that call will fail, and the shutter sound will be played when takePicture is called. facing Added in API level 9 public int facing The direction that the camera faces. It should be CAMERA_FACING_BACK or CAMERA_FACING_FRONT. orientation Added in API level 9 public int orientation The orientation of the camera image. The value is the angle that the camera image needs to be rotated clockwise so it shows correctly on the display in its natural orientation. It should be 0, 90, 180, or 270. For example, suppose a device has a naturally tall screen. The back-facing camera sensor is mounted in landscape. You are looking at the screen. If the top side of the camera sensor is aligned with the right edge of the screen in natural orientation, the value should be 90. If the top side of a front-facing camera sensor is aligned with the right of the screen, the value should be 270.
