CaptureFailure Kotlin | Java public class CaptureFailure extends Object java.lang.Object ↳ android.hardware.camera2.CaptureFailure A report of failed capture for a single image capture from the image sensor. CaptureFailures are produced by a CameraDevice if processing a CaptureRequest fails, either partially or fully. Use getReason() to determine the specific nature of the failed capture. Receiving a CaptureFailure means that the metadata associated with that frame number has been dropped -- no CaptureResult with the same frame number will be produced.
