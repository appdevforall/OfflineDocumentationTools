DeviceStateSensorOrientationMap Kotlin | Java public final class DeviceStateSensorOrientationMap extends Object java.lang.Object ↳ android.hardware.camera2.params.DeviceStateSensorOrientationMap Immutable class that maps the device fold state to sensor orientation. Some logical cameras on foldables can include physical sensors with different sensor orientation values. As a result, the values of the logical camera device can potentially change depending on the device fold state. The device fold state to sensor orientation map will contain information about the respective logical camera sensor orientation given a device state. Clients can query the mapping for all possible supported folded states.
