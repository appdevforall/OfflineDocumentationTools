Camera clients must always retrieve the value of CameraCharacteristics.REQUEST_AVAILABLE_COLOR_SPACE_PROFILES . for a given camera id in order to retrieve the device capabilities. Parameters elements long : An array of elements describing the map. It contains three elements per entry which describe the supported color space profile value in the first element, a compatible image format in the second, and in the third element a bitmap of compatible dynamic range profiles (see DynamicRangeProfiles.STANDARD and others for the individual bitmap components). This value cannot be null .
