TonemapCurve Kotlin | Java public final class TonemapCurve extends Object java.lang.Object ↳ android.hardware.camera2.params.TonemapCurve Immutable class for describing a 2 x M x 3 tonemap curve of floats. This defines red, green, and blue curves that the CameraDevice will use as the tonemapping/contrast/gamma curve when CaptureRequest.TONEMAP_MODE is set to CameraMetadata.TONEMAP_MODE_CONTRAST_CURVE . For a camera device with MONOCHROME capability, all 3 channels will contain the same set of control points. The total number of points (Pin, Pout) for each color channel can be no more than CameraCharacteristics.TONEMAP_MAX_CURVE_POINTS . The coordinate system for each point is within the inclusive range [ .LEVEL_BLACK , .LEVEL_WHITE ].
