TextRunShaper Kotlin | Java public class TextRunShaper extends Object java.lang.Object ↳ android.graphics.text.TextRunShaper Provides conversion from a text into glyph array. Text shaping is a preprocess for drawing text into canvas with glyphs. The glyph is a most primitive unit of the text drawing, consist of glyph identifier in the font file and its position and style. You can draw the shape result to Canvas by calling Canvas#drawGlyphs. For most of the use cases, TextShaper will provide text shaping functionalities needed. TextRunShaper is a lower level API that is used by TextShaper .
