MeshSpecification.Attribute Kotlin | Java public static class MeshSpecification.Attribute extends Object java.lang.Object ↳ android.graphics.MeshSpecification.Attribute Data class to represent a single attribute in a shader. An attribute is a variable that accompanies a vertex, this can be a color or texture coordinates. See https://developer.android.com/develop/ui/views/graphics/agsl for more information regarding Android Graphics Shader Language. Note that offset is the offset in number of bytes. For example, if we had two attributes Float3 att1 Float att2 att1 would have an offset of 0, while att2 would have an offset of 12 bytes. This is consumed as part of MeshSpecification.make(Attribute[], int, Varying[], String, String, ColorSpace, int) to create a MeshSpecification instance.
