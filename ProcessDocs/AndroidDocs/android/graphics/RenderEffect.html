RenderEffect Kotlin | Java public final class RenderEffect extends Object java.lang.Object ↳ android.graphics.RenderEffect Intermediate rendering step used to render drawing commands with a corresponding visual effect. A RenderEffect can be configured on a RenderNode through RenderNode.setRenderEffect(RenderEffect) and will be applied when drawn through Canvas.drawRenderNode(RenderNode) .
