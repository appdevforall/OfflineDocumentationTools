Drawable.ConstantState Kotlin | Java public static abstract class Drawable.ConstantState extends Object java.lang.Object ↳ android.graphics.drawable.Drawable.ConstantState Known direct subclasses DrawableContainer.DrawableContainerState DrawableContainer.DrawableContainerState A ConstantState that can contain several Drawable s. This abstract class is used by Drawable s to store shared constant state and data between Drawables. BitmapDrawable s created from the same resource will for instance share a unique bitmap stored in their ConstantState. newDrawable(android.content.res.Resources) can be used as a factory to create new Drawable instances from this ConstantState. Use Drawable.getConstantState() to retrieve the ConstantState of a Drawable. Calling Drawable.mutate() on a Drawable should typically create a new ConstantState for that Drawable.
