Icon Kotlin | Java public final class Icon extends Object implements Parcelable java.lang.Object ↳ android.graphics.drawable.Icon An umbrella container for several serializable graphics representations, including Bitmaps, compressed bitmap images (e.g. JPG or PNG), and drawable resources (including vectors). Much ink has been spilled on the best way to load images, and many clients may have different needs when it comes to threading and fetching. This class is therefore focused on encapsulation rather than behavior.
