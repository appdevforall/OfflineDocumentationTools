Public constructors PathDashPathEffect Added in API level 1 public PathDashPathEffect ( Path shape, float advance, float phase, PathDashPathEffect.Style style) Dash the drawn path by stamping it with the specified shape. This only applies to drawings when the paint's style is STROKE or STROKE_AND_FILL. If the paint's style is FILL, then this effect is ignored. The paint's strokeWidth does not affect the results. Parameters shape Path : The path to stamp along advance float : spacing between each stamp of shape phase float : amount to offset before the first shape is stamped style PathDashPathEffect.Style : how to transform the shape at each position as it is stamped
