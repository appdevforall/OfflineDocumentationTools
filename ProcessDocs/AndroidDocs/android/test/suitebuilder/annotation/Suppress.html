Suppress Kotlin | Java public abstract @interface Suppress implements Annotation android.test.suitebuilder.annotation.Suppress This @interface was deprecated in API level 24. Use Suppress instead. New tests should be written using the Android Testing Support Library . Use this annotation on test classes or test methods that should not be included in a test suite. If the annotation appears on the class then no tests in that class will be included. If the annotation appears only on a test method then only that method will be excluded.
