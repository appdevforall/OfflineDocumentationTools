ServiceWorkerWebSettings Kotlin | Java public abstract class ServiceWorkerWebSettings extends Object java.lang.Object ↳ android.webkit.ServiceWorkerWebSettings Manages settings state for all Service Workers. These settings are not tied to the lifetime of any WebView because service workers can outlive WebView instances. The settings are similar to WebSettings but only settings relevant to Service Workers are supported.
