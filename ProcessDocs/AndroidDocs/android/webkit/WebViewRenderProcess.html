Calling this on a not yet started, or an already terminated renderer will have no effect. Terminating a renderer process may have an effect on multiple WebView instances. Renderer termination must be handled by properly overriding WebViewClient.onRenderProcessGone for every WebView that shares this renderer. If termination is not handled by all associated WebViews, then the application process will also be terminated. Returns boolean true if it was possible to terminate this renderer, false otherwise.
