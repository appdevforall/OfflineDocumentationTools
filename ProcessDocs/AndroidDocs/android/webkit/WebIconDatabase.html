This class is only required when running on devices up to Build.VERSION_CODES.JELLY_BEAN_MR2 Functions for manipulating the icon database used by WebView. These functions require that a WebView be constructed before being invoked and WebView.getIconDatabase() will return a WebIconDatabase object. This WebIconDatabase object is a single instance and all methods operate on that single object. The main use-case for this class is calling open(String) to enable favicon functionality on all WebView instances in this process.
