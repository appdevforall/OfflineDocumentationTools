FhirVersion Kotlin | Java public final class FhirVersion extends Object implements Parcelable java.lang.Object ↳ android.health.connect.datatypes.FhirVersion Represents the FHIR version. This is designed according to the official FHIR versions of the Fast Healthcare Interoperability Resources (FHIR) standard. "label", which represents a 'working' version, is not supported for now. The versions R4 (4.0.1) and R4B (4.3.0) are supported in Health Connect.
