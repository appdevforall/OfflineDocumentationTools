Parameters fhirBaseUri Uri : The FHIR base URI of the data source. For data coming from a FHIR server this should be the FHIR base URL (e.g. `https://example.com/fhir`). If the data is generated by an app without a FHIR URL, this can be populated by a unique and understandable URI defined by the app (e.g. `myapp://..`) that points to the source of the data.
