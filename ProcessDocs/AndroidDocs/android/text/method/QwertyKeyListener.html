QwertyKeyListener Kotlin | Java public class QwertyKeyListener extends BaseKeyListener java.lang.Object ↳ android.text.method.MetaKeyKeyListener ↳ android.text.method.BaseKeyListener ↳ android.text.method.QwertyKeyListener This is the standard key listener for alphabetic input on qwerty keyboards. You should generally not need to instantiate this yourself; TextKeyListener will do it for you. As for all implementations of KeyListener , this class is only concerned with hardware keyboards. Software input methods have no obligation to trigger the methods in this class.
