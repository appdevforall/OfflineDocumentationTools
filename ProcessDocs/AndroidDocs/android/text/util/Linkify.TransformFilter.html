Linkify.TransformFilter Kotlin | Java public static interface Linkify.TransformFilter android.text.util.Linkify.TransformFilter TransformFilter enables client code to have more control over how matched patterns are represented as URLs. For example: when converting a phone number such as (919) 555-1212 into a tel: URL the parentheses, white space, and hyphen need to be removed to produce tel:9195551212.
