There should only be one LeadingMarginSpan2 per paragraph. The leading margin line count affects all LeadingMarginSpans in the paragraph, adjusting the number of lines to which the first line margin is applied. As with LeadingMarginSpans, LeadingMarginSpan2s should be attached from the beginning to the end of a paragraph.
