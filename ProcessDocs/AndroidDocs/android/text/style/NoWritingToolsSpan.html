NoWritingToolsSpan Kotlin | Java public final class NoWritingToolsSpan extends Object implements ParcelableSpan java.lang.Object ↳ android.text.style.NoWritingToolsSpan A span that signals to IMEs that writing tools should not modify the text. For example, a text field may contain a mix of user input text and quoted text. The app can apply NoWritingToolsSpan to the quoted text so that the IME knows that writing tools should only rewrite the user input text, and not modify the quoted text.
