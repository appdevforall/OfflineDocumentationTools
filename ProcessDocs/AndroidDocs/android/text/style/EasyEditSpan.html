EasyEditSpan Kotlin | Java public class EasyEditSpan extends Object implements ParcelableSpan java.lang.Object ↳ android.text.style.EasyEditSpan Provides an easy way to edit a portion of text. The TextView uses this span to allow the user to delete a chuck of text in one click. TextView removes the span when the user deletes the whole text or modifies it.
