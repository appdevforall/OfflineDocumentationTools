Layout.Builder Kotlin | Java public static final class Layout.Builder extends Object java.lang.Object ↳ android.text.Layout.Builder A builder class for Layout object. Different from StaticLayout.Builder , this builder generates the optimal layout based on input. If the given text and parameters can be rendered with BoringLayout , this builder generates BoringLayout instance. Otherwise, StaticLayout instance is generated.
