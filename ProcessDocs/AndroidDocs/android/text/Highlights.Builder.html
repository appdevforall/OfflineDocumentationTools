The TextView and underlying Layout draws highlight in the order of the addRange(Paint, int, int) calls. For example, the following code draws (1, 2) with red and (2, 5) with blue. val redPaint = Paint().apply { color = Color.RED } val bluePaint = Paint().apply { color = Color.BLUE } val highlight = Highlights.Builder() .addRange(redPaint, 1, 4) .addRange(bluePaint, 2, 5) .build() Parameters paint Paint : a paint object used for drawing highlight path. start int : an inclusive offset of the text. end int : an exclusive offset of the text.
