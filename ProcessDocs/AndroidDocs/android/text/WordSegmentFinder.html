WordSegmentFinder Kotlin | Java public class WordSegmentFinder extends SegmentFinder java.lang.Object ↳ android.text.SegmentFinder ↳ android.text.WordSegmentFinder Implementation of SegmentFinder using words as the text segment. Word boundaries are found using WordIterator . Whitespace characters are excluded, so they are not included in any text segments. For example, the text "Hello, World!" would be subdivided into four text segments: "Hello", ",", "World", "!". The space character does not belong to any text segments.
