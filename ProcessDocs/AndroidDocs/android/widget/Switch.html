Switch Kotlin | Java public class Switch extends CompoundButton java.lang.Object ↳ android.view.View ↳ android.widget.TextView ↳ android.widget.Button ↳ android.widget.CompoundButton ↳ android.widget.Switch A Switch is a two-state toggle widget. Users can drag the switch "thumb" back and forth to select either of two options or simply tap the switch to toggle between options. The text property controls the text of the switch label. The textOn and textOff properties control the text of the thumb. The textAppearance property and the related setTypeface() methods control the typeface and style of the switch label. The switchTextAppearance property and the related setSwitchTypeface() methods control the typeface and style of the thumb text. Note: The thumb text is displayed only if the showText attribute is set to true . See also setShowText(boolean) and getShowText() . SwitchCompat provides backward compatibility down to Android 4.0 (API level 14). For more information, see the Toggle Buttons guide.
