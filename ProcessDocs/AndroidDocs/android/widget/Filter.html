Filter Kotlin | Java public abstract class Filter extends Object java.lang.Object ↳ android.widget.Filter A filter constrains data with a filtering pattern. Filters are usually created by Filterable classes. Filtering operations performed by calling filter(java.lang.CharSequence) or filter(java.lang.CharSequence, android.widget.Filter.FilterListener) are performed asynchronously. When these methods are called, a filtering request is posted in a request queue and processed later. Any call to one of these methods will cancel any previous non-executed filtering request.
