ListPopupWindow Kotlin | Java public class ListPopupWindow extends Object java.lang.Object ↳ android.widget.ListPopupWindow A ListPopupWindow anchors itself to a host view and displays a list of choices. ListPopupWindow contains a number of tricky behaviors surrounding positioning, scrolling parents to fit the dropdown, interacting sanely with the IME if present, and others.
