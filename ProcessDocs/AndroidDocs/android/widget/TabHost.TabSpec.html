TabHost.TabSpec Kotlin | Java public class TabHost.TabSpec extends Object java.lang.Object ↳ android.widget.TabHost.TabSpec A tab has a tab indicator, content, and a tag that is used to keep track of it. This builder helps choose among these options. For the tab indicator, your choices are: 1) set a label 2) set a label and an icon For the tab content, your choices are: 1) the id of a View 2) a TabContentFactory that creates the View content. 3) an Intent that launches an Activity .
