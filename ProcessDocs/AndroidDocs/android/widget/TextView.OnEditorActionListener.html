Public methods onEditorAction Added in API level 3 public abstract boolean onEditorAction ( TextView v, int actionId, KeyEvent event) Called when an action is being performed. Parameters v TextView : The view that was clicked. actionId int : Identifier of the action. This will be either the identifier you supplied, or EditorInfo.IME_NULL if being called due to the enter key being pressed. Starting from Android 14, the action identifier will also be included when triggered by an enter key if the input is constrained to a single line. event KeyEvent : If triggered by an enter key, this is the event; otherwise, this is null. Returns boolean Return true if you have consumed the action, else false.
