PopupMenu Kotlin | Java public class PopupMenu extends Object java.lang.Object ↳ android.widget.PopupMenu A PopupMenu displays a Menu in a modal popup window anchored to a View . The popup will appear below the anchor view if there is room, or above it if there is not. If the IME is visible the popup will not overlap it until it is touched. Touching outside of the popup will dismiss it.
