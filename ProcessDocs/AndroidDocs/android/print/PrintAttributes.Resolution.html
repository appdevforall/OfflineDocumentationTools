PrintAttributes.Resolution Kotlin | Java public static final class PrintAttributes.Resolution extends Object java.lang.Object ↳ android.print.PrintAttributes.Resolution This class specifies a supported resolution in DPI (dots per inch). Resolution defines how many points with different color can be placed on one inch in horizontal or vertical direction of the target media. For example, a printer with 600 DPI can produce higher quality images the one with 300 DPI resolution.
