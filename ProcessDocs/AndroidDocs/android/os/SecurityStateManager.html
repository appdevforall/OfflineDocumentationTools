Each key-value pair is a mapping of a component of the global security state to its current version/SPL (security patch level). For example, the KEY_SYSTEM_SPL key will map to the SPL of the system as defined in Build.VERSION . The bundle will also include mappings from WebView packages and packages listed under config config_securityStatePackages to their respective versions as defined in PackageInfo.versionName . Returns Bundle A Bundle that contains the global security state information as string-to-string key-value pairs. This value cannot be null .
