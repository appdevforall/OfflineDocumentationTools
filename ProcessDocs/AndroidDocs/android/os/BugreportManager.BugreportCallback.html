BugreportManager.BugreportCallback Kotlin | Java public static abstract class BugreportManager.BugreportCallback extends Object java.lang.Object ↳ android.os.BugreportManager.BugreportCallback An interface describing the callback for bugreport progress and status. Callers will receive onProgress(float) calls as the bugreport progresses, followed by a terminal call to either onFinished() or onError(int) . If an issue is encountered while starting the bugreport asynchronously, callers will receive an onError(int) call without any onProgress(float) callbacks. If BUGREPORT_ERROR_USER_DENIED_CONSENT is passed, then the user did not consent to sharing the bugreport with the calling app. If BUGREPORT_ERROR_USER_CONSENT_TIMED_OUT is passed, then the consent timed out, but the bugreport could be available in the internal directory of dumpstate for manual retrieval. If BUGREPORT_ERROR_ANOTHER_REPORT_IN_PROGRESS is passed, then the caller should try later, as only one bugreport can be in progress at a time.
