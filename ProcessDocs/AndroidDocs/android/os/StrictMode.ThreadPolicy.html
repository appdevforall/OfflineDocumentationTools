StrictMode.ThreadPolicy Kotlin | Java public static final class StrictMode.ThreadPolicy extends Object java.lang.Object ↳ android.os.StrictMode.ThreadPolicy StrictMode policy applied to a certain thread. The policy is enabled by StrictMode.setThreadPolicy(ThreadPolicy) . The current policy can be retrieved with StrictMode.getThreadPolicy() . Note that multiple penalties may be provided and they're run in order from least to most severe (logging before process death, for example). There's currently no mechanism to choose different penalties for different detected actions. Summary Nested classes class StrictMode.ThreadPolicy.Builder Creates ThreadPolicy instances.
