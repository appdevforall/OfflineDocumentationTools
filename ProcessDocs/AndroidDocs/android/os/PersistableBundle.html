PersistableBundle Kotlin | Java public final class PersistableBundle extends BaseBundle implements Cloneable , Parcelable java.lang.Object ↳ android.os.BaseBundle ↳ android.os.PersistableBundle A mapping from String keys to values of various types. The set of types supported by this class is purposefully restricted to simple objects that can safely be persisted to and restored from disk. Warning: Note that PersistableBundle is a lazy container and as such it does NOT implement Object.equals(java.lang.Object) or Object.hashCode() .
