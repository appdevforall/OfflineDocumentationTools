OutcomeReceiver Kotlin | Java public interface OutcomeReceiver android.os.OutcomeReceiver Callback interface intended for use when an asynchronous operation may result in a failure. This interface may be used in cases where an asynchronous API may complete either with a value or with a Throwable that indicates an error. Summary Public methods default void onError (E error) Called when the asynchronous operation fails. abstract void onResult (R result) Called when the asynchronous operation succeeds and delivers a result value.
