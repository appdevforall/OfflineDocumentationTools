View.OnGenericMotionListener Kotlin | Java public static interface View.OnGenericMotionListener android.view.View.OnGenericMotionListener Interface definition for a callback to be invoked when a generic motion event is dispatched to this view. The callback will be invoked before the generic motion event is given to the view.
