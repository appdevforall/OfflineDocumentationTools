ViewTreeObserver Kotlin | Java public final class ViewTreeObserver extends Object java.lang.Object ↳ android.view.ViewTreeObserver A view tree observer is used to register listeners that can be notified of global changes in the view tree. Such global events include, but are not limited to, layout of the whole tree, beginning of the drawing pass, touch mode change.... A ViewTreeObserver should never be instantiated by applications as it is provided by the views hierarchy. Refer to View.getViewTreeObserver() for more information.
