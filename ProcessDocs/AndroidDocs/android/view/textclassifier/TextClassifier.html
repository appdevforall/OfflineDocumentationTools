TextClassifier Kotlin | Java public interface TextClassifier android.view.textclassifier.TextClassifier Interface for providing text classification related features. The TextClassifier may be used to understand the meaning of text, as well as generating predicted next actions based on the text. NOTE: Unless otherwise stated, methods of this interface are blocking operations. Call on a worker thread.
