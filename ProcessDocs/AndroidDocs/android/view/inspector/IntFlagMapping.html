IntFlagMapping Kotlin | Java public final class IntFlagMapping extends Object java.lang.Object ↳ android.view.inspector.IntFlagMapping Maps the values of an int property to sets of string for properties that encode flags. An InspectionCompanion may provide an instance of this class to a PropertyMapper for flag values packed into primitive int properties. Each flag has a mask and a target value, for non-exclusive flags, the target can also be used as the mask. A given integer value is compared against each flag to find what flags are active for it by bitwise anding it with the mask and comparing the result against the target, that is, (value & mask) == target .
