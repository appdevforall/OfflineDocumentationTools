You can use this to customize the tag names available in your XML layout files. Note that it is good practice to prefix these custom names with your package (i.e., com.coolcompany.apps) to avoid conflicts with system names. Parameters name String : Tag name to be inflated. This value cannot be null . context Context : The context the view is being created in. This value cannot be null . attrs AttributeSet : Inflation attributes as specified in XML file.
