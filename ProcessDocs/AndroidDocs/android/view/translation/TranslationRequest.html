The partial responses can be accessed by TranslationResponse.getTranslationResponseValues() or TranslationResponse.getViewTranslationResponses() . These responses will each contain only a subset of the corresponding translated values. The are no guarantees to the number of translated values or the order in which these values are returned in the TranslationResponse . This flag denotes the client can expect multiple partial responses, but there may not necessarily be multiple responses.
