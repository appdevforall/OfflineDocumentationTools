CollapsibleActionView Kotlin | Java public interface CollapsibleActionView android.view.CollapsibleActionView Known indirect subclasses SearchView SearchView A widget that provides a user interface for the user to enter a search query and submit a request to a search provider. When a View implements this interface it will receive callbacks when expanded or collapsed as an action view alongside the optional, app-specified callbacks to OnActionExpandListener .
