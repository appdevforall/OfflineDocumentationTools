View.OnScrollChangeListener Kotlin | Java public static interface View.OnScrollChangeListener android.view.View.OnScrollChangeListener Interface definition for a callback to be invoked when the scroll X or Y positions of a view change. Note: Some views handle scrolling independently from View and may have their own separate listeners for scroll-type events. For example, ListView allows clients to register an AbsListView.OnScrollListener to listen for changes in list scroll position.
