DisplayHashResultCallback Kotlin | Java public interface DisplayHashResultCallback android.view.displayhash.DisplayHashResultCallback Use when calling View.generateDisplayHash(String, Rect, Executor, DisplayHashResultCallback) . The callback will only invoke either onDisplayHashResult(DisplayHash) when the system successfully generated the DisplayHash or onDisplayHashError(int) when it failed.
