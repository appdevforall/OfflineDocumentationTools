SubMenu

Kotlin |Java

public interface SubMenu
implements Menu

android.view.SubMenu

Subclass of Menu for sub menus.

Sub menus do not support item icons, or nested sub menus.

Developer Guides

For information about creating menus, read the Menus developer guide.
