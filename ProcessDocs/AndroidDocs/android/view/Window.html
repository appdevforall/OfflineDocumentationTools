Window Kotlin | Java public abstract class Window extends Object java.lang.Object ↳ android.view.Window Abstract base class for a top-level window look and behavior policy. An instance of this class should be used as the top-level view added to the window manager. It provides standard UI policies such as a background, title area, default key processing, etc. The framework will instantiate an implementation of this class on behalf of the application.
