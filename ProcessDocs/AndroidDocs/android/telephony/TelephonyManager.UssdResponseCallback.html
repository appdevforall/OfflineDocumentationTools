Public constructors UssdResponseCallback public UssdResponseCallback () Public methods onReceiveUssdResponse Added in API level 26 public void onReceiveUssdResponse ( TelephonyManager telephonyManager, String request, CharSequence response) Called when a USSD request has succeeded. The response contains the USSD response received from the network. The calling app can choose to either display the response to the user or perform some operation based on the response. USSD responses are unstructured text and their content is determined by the mobile network operator.
