ImsReasonInfo Kotlin | Java public final class ImsReasonInfo extends Object implements Parcelable java.lang.Object ↳ android.telephony.ims.ImsReasonInfo Provides details on why an IMS call failed. Applications can use the methods in this class to get local or network fault behind an IMS services failure. For example, if the code is CODE_CALL_BARRED, then the call was blocked by network call barring configuration and it is not the device's bug and the user can retry the call when network lift the barring. Typical use case includes call backs when IMS call state changed with this class as a param containing details on why IMS call changed state/failed.
