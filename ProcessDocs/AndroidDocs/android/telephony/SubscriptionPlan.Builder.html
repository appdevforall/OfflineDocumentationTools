When the given period is set to exactly one month, the plan will always recur on the day of the month defined by ZonedDateTime.getDayOfMonth() . When a particular month ends before this day, the plan will recur on the last possible instant of that month. Parameters start ZonedDateTime : The exact time at which the plan starts. period Period : The period after which the plan automatically recurs.
