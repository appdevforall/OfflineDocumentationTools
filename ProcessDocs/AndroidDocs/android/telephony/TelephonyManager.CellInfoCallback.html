Invoked when an error condition prevents updated CellInfo from being fetched and returned from the modem. Callers of requestCellInfoUpdate() should override this function to receive detailed status information in the event of an error. By default, this function will invoke onCellInfo() with null. Parameters errorCode int : an error code indicating the type of failure. Value is ERROR_TIMEOUT , or ERROR_MODEM_ERROR detail Throwable : a Throwable object with additional detail regarding the failure if available, otherwise null.
