PolicyUpdateReceiver Kotlin | Java public abstract class PolicyUpdateReceiver extends BroadcastReceiver java.lang.Object ↳ android.content.BroadcastReceiver ↳ android.app.admin.PolicyUpdateReceiver Base class for implementing a policy update receiver. This class provides a convenience for interpreting the raw intent actions ( ACTION_DEVICE_POLICY_SET_RESULT and ACTION_DEVICE_POLICY_CHANGED ) that are sent by the system. The callback methods happen on the main thread of the process. Thus, long-running operations must be done on another thread. When publishing your PolicyUpdateReceiver subclass as a receiver, it must require the Manifest.permission.BIND_DEVICE_ADMIN permission. Admins can implement DeviceAdminService to ensure they receive all policy updates (for policies they have set) via onPolicyChanged(Context, String, Bundle, TargetUser, PolicyUpdateResult) by constantly being bound to by the system. For more information see DeviceAdminService .
