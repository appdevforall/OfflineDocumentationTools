Constants HEADLESS_DEVICE_OWNER_MODE_AFFILIATED Added in API level 34 public static final int HEADLESS_DEVICE_OWNER_MODE_AFFILIATED Value for getHeadlessDeviceOwnerMode() which indicates that this DPC should be provisioned into "affiliated" mode when on a Headless System User Mode device. This mode adds a Profile Owner to all users other than the user the Device Owner is on. Starting from Android version Build.VERSION_CODES.VANILLA_ICE_CREAM , DPCs should set the value of attribute "headless-device-owner-mode" inside the "headless-system-user" tag as "affiliated".
