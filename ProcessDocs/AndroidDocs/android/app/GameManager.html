Constant Value: 0 (0x00000000) Public methods getGameMode Added in API level 31 public int getGameMode () Return the user selected game mode for this application. An application can use android:isGame="true" or android:appCategory="game" to indicate that the application is a game. If an application is not a game, always return GAME_MODE_UNSUPPORTED . Developers should call this API every time the application is resumed. If a game's targetSdkVersion is Build.VERSION_CODES.TIRAMISU or lower, and when the game mode is set to GAME_MODE_CUSTOM which is available in Build.VERSION_CODES.UPSIDE_DOWN_CAKE or newer, this API will return GAME_MODE_STANDARD instead for backward compatibility.
