GameState Kotlin | Java public final class GameState extends Object implements Parcelable java.lang.Object ↳ android.app.GameState State of the game passed to the GameManager. This includes a top-level state for the game (indicating if the game can be interrupted without interfering with content that can't be paused). Since content can be loaded in any state, it includes an independent boolean flag to indicate loading status. Free-form metadata (as a Bundle) and a string description can also be specified by the application.
