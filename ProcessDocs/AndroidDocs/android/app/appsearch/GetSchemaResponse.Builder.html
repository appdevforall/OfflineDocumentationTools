The requirements in a SchemaVisibilityConfig is "AND" relationship. A caller must match ALL requirements to access the schema. For example, a caller must hold required permissions AND it is a specified package. The querier could have access if they match ALL requirements in ANY of the given SchemaVisibilityConfig s For example, if the Set contains {{PackageA and Permission1}, {PackageB and Permission2}} .
