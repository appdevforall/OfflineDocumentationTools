See also: GenericDocument.Builder.setPropertyBlobHandle(String, AppSearchBlobHandle) registerObserverCallback Added in API level 33 Also in T Extensions 3 public void registerObserverCallback ( String targetPackageName, ObserverSpec spec, Executor executor, ObserverCallback observer) Adds an ObserverCallback to monitor changes within the databases owned by targetPackageName if they match the given ObserverSpec . The observer callback is only triggered for data that changes after it is registered. No notification about existing data is sent as a result of registering an observer. To find out about existing data, you must use the GlobalSearchSession.search API. If the data owned by targetPackageName is not visible to you, the registration call will succeed but no notifications will be dispatched. Notifications could start flowing later if targetPackageName changes its schema visibility settings. If no package matching targetPackageName exists on the system, the registration call will succeed but no notifications will be dispatched. Notifications could start flowing later if targetPackageName is installed and starts indexing data.
