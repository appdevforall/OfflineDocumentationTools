Returns SchemaVisibilityConfig.Builder This value cannot be null . setPubliclyVisibleTargetPackage Added in API level 35 Also in T Extensions 13 public SchemaVisibilityConfig.Builder setPubliclyVisibleTargetPackage ( PackageIdentifier packageIdentifier) Specify that this schema should be publicly available, to the same packages that have visibility to the package passed as a parameter. This visibility is determined by the result of PackageManager.canPackageQuery(String, String) . It is possible for the packageIdentifier parameter to be different from the package performing the indexing. This might happen in the case of an on-device indexer processing information about various packages. The visibility will be the same regardless of which package indexes the document, as the visibility is based on the packageIdentifier parameter. Calling this with packageIdentifier set to null is valid, and will remove public visibility for the schema. Parameters packageIdentifier PackageIdentifier : the PackageIdentifier of the package that will be used as the target package in a call to PackageManager.canPackageQuery(String, String) to determine which packages can access this publicly visible schema.
