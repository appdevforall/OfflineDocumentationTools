SearchResult Kotlin | Java public final class SearchResult extends Object implements Parcelable java.lang.Object ↳ android.app.appsearch.SearchResult This class represents one of the results obtained from an AppSearch query. This allows clients to obtain: The document which matched, using getGenericDocument() Information about which properties in the document matched, and "snippet" information containing textual summaries of the document's matches, using getMatchInfos() "Snippet" refers to a substring of text from the content of document that is returned as a part of search result.
