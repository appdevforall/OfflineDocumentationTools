LocaleConfig Kotlin | Java public class LocaleConfig extends Object implements Parcelable java.lang.Object ↳ android.app.LocaleConfig The LocaleConfig of an application. There are two sources. One is from an XML resource file with an element and referenced in the manifest via android:localeConfig on . The other is that the application dynamically provides an override version which is persisted in LocaleManager.setOverrideLocaleConfig(LocaleConfig) . For more information about the LocaleConfig from an XML resource file, see the section on per-app language preferences .
