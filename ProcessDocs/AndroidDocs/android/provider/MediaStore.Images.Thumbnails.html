This class was deprecated in API level 29.
Callers should migrate to using ContentResolver.loadThumbnail, since it offers richer control over requested thumbnail sizes and cancellation behavior.

This class provides utility methods to obtain thumbnails for various Images items.

This method was deprecated in API level 29.

Return thumbnail representing a specific image item. If a thumbnail doesn't exist, this method will block until it's generated.
