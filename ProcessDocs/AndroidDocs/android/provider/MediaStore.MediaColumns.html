This is useful for apps that are attempting to quickly identify exactly which media items have been added since a previous point in time. Generation numbers are monotonically increasing over time, and can be safely arithmetically compared. Detecting media additions using generation numbers is more robust than using DATE_ADDED , since those values may change in unexpected ways when apps use File.setLastModified(long) or when the system clock is set incorrectly. Note that before comparing these detailed generation values, you should first confirm that the overall version hasn't changed by checking MediaStore.getVersion(Context, String) , since that indicates when a more radical change has occurred. If the overall version changes, you should assume that generation numbers have been reset and perform a full synchronization pass.
