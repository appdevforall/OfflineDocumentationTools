DocumentsContract.Root Kotlin | Java public static final class DocumentsContract.Root extends Object java.lang.Object ↳ android.provider.DocumentsContract.Root Constants related to a root of documents, including Cursor column names and flags. A root is the start of a tree of documents, such as a physical storage device, or an account. Each root starts at the directory referenced by Root.COLUMN_DOCUMENT_ID , which can recursively contain both documents and directories. All columns are read-only to client applications.
