OnNmeaMessageListener Kotlin | Java public interface OnNmeaMessageListener android.location.OnNmeaMessageListener Used for receiving NMEA sentences from the GNSS. NMEA 0183 is a standard for communicating with marine electronic devices and is a common method for receiving data from a GNSS, typically over a serial port. See NMEA 0183 for more details. You can implement this interface and call LocationManager.addNmeaListener(Executor, OnNmeaMessageListener) to receive NMEA data from the GNSS engine.
