Constraints Artifact: androidx.work:work-runtime View Source Added in 1.0.0 Kotlin | Java public final class Constraints A specification of the requirements that need to be met before a WorkRequest can run. By default, WorkRequests do not have any requirements and can run immediately. By adding requirements, you can make sure that work only runs in certain situations - for example, when you have an unmetered network and are charging.
