AnimatorInflater Artifact: androidx.core:core-animation View Source Kotlin | Java public class AnimatorInflater This class is used to instantiate animator XML files into Animator objects. For performance reasons, inflation relies heavily on pre-processing of XML files that is done at build time. Therefore, it is not currently possible to use this inflater with an XmlPullParser over a plain XML file at runtime; it only works with an XmlPullParser returned from a compiled resource (R. something file.)
