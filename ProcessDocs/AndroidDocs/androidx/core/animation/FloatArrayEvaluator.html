FloatArrayEvaluator Artifact: androidx.core:core-animation View Source Kotlin | Java public final class FloatArrayEvaluator implements TypeEvaluator This evaluator can be used to perform type interpolation between float[] values. Each index into the array is treated as a separate value to interpolate. For example, evaluating {100, 200} and {300, 400} will interpolate the value at the first index between 100 and 300 and the value at the second index value between 200 and 400.
