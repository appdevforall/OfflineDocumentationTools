SplashScreenViewProvider Artifact: androidx.core:core-splashscreen View Source Added in 1.0.0 Kotlin | Java public final class SplashScreenViewProvider Contains a copy of the splash screen used to create a custom animation from the splash screen to the application. The splashscreen is accessible using SplashScreenViewProvider.view and the view containing the icon using SplashScreenViewProvider.iconView . This class also contains time information about the animated icon (for API 31+). The application always needs to call SplashScreenViewProvider.remove once it's done with it.
