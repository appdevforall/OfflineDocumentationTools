ActivityCompat.PermissionCompatDelegate Artifact: androidx.core:core View Source Added in 1.1.0 Kotlin | Java public interface ActivityCompat.PermissionCompatDelegate Customizable delegate that allows delegating permission compatibility methods to a custom implementation. To delegate permission compatibility methods to a custom class, implement this interface, and call ActivityCompat.setPermissionCompatDelegate(delegate); . All future calls to the permission compatibility methods in this class will first check whether the delegate can handle the method call, and invoke the corresponding method if it can.
