MailTo Artifact: androidx.core:core View Source Added in 1.5.0 Kotlin | Java public final class MailTo MailTo URI parser. Replacement for android.net.MailTo . This class parses a mailto scheme URI and then can be queried for the parsed parameters. This implements RFC 6068. Note: scheme name matching is case-sensitive, unlike the formal RFC. As a result, you should always ensure that you write your URI with the scheme using lower case letters, and normalize any URIs you receive from outside of Android to ensure the scheme is lower case.
