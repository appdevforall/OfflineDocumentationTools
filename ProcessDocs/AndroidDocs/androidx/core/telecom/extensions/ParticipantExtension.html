ParticipantExtension Artifact: androidx.core:core-telecom View Source Added in 1.0.0 Kotlin | Java @ ExperimentalAppActions public interface ParticipantExtension The extension interface used to support notifying remote surfaces (automotive, watch, etc...) of state related to the Participant s in the call. This interface allows an application to notify remote surfaces of changes to Participant state. Additionally, this interface allows the application to support optional actions that use the participant state. These actions provide remote surfaces with the ability to request participant state updates based on user input and provide additional information about the state of specific participants.
