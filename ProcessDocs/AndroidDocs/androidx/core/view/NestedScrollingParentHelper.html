NestedScrollingParentHelper Artifact: androidx.core:core View Source Added in 1.1.0 Kotlin | Java public class NestedScrollingParentHelper Helper class for implementing nested scrolling parent views compatible with Android platform versions earlier than Android 5.0 Lollipop (API 21). ViewGroup subclasses should instantiate a final instance of this class as a field at construction. For each ViewGroup method that has a matching method signature in this class, delegate the operation to the helper instance in an overridden method implementation. This implements the standard framework policy for nested scrolling. Views invoking nested scrolling functionality should always do so from the relevant androidx.core.view.ViewCompat , androidx.core.view.ViewGroupCompat or androidx.core.view.ViewParentCompat compatibility shim static methods. This ensures interoperability with nested scrolling views on Android 5.0 Lollipop and newer.
