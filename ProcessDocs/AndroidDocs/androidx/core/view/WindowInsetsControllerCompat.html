WindowInsetsControllerCompat Artifact: androidx.core:core View Source Added in 1.5.0 Kotlin | Java public final class WindowInsetsControllerCompat Provide simple controls of windows that generate insets. For SDKs >= 30, this class is a simple wrapper around WindowInsetsController . For lower SDKs, this class aims to behave as close as possible to the original implementation.
