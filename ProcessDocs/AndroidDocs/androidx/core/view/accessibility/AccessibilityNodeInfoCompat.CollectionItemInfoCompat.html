AccessibilityNodeInfoCompat.CollectionItemInfoCompat Artifact: androidx.core:core View Source Added in 1.1.0 Kotlin | Java public class AccessibilityNodeInfoCompat.CollectionItemInfoCompat Class with information if a node is a collection item. A collection item is contained in a collection, it starts at a given row and column in the collection, and spans one or more rows and columns. For example, a header of two related table columns starts at the first row and the first column, spans one row and two columns.
