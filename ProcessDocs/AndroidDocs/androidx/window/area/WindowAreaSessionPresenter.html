WindowAreaSessionPresenter Artifact: androidx.window:window View Source Added in 1.2.0 Kotlin | Java @ ExperimentalWindowApi public interface WindowAreaSessionPresenter extends WindowAreaSession A container that allows getting access to and showing content on a window area. The container is provided from WindowAreaPresentationSessionCallback when a requested session becomes active. The presentation can be automatically dismissed by the system when the user leaves the primary application window, or can be closed by calling WindowAreaSessionPresenter.close .
