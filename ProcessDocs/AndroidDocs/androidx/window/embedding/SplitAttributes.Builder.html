SplitAttributes.Builder Artifact: androidx.window:window View Source Added in 1.1.0 Kotlin | Java public final class SplitAttributes.Builder Builder for creating an instance of SplitAttributes . The default split type is an equal split between primary and secondary containers. The default layout direction is based on locale.
