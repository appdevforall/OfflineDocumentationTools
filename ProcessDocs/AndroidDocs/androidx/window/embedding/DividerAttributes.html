Some devices may choose 0 as the default width, while the same app may be shown with a wider divider on other devices that have a different default value. If an app prefers to show a divider of a fixed width on all device, it should set the fixed width in FixedDividerAttributes.Builder.setWidthDp or DraggableDividerAttributes.Builder.setWidthDp .
