ExerciseLap Artifact: androidx.health.connect:connect-client View Source Added in 1.1.0-rc02 Kotlin | Java public final class ExerciseLap Captures the time of a lap within an exercise session. Each lap contains the start and end time and optional [Length] of the lap (e.g. pool length while swimming or a track lap while running). There may or may not be direct correlation with [ExerciseSegment] start and end times, e.g. [ExerciseSessionRecord] of type running without any segments can be divided into laps of different lengths.
