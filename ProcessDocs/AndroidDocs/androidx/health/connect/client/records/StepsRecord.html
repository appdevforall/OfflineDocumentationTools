StepsRecord Artifact: androidx.health.connect:connect-client View Source Added in 1.1.0-rc02 Kotlin | Java public final class StepsRecord implements Record Captures the number of steps taken since the last reading. Each step is only reported once so records shouldn't have overlapping time. The start time of each record should represent the start of the interval in which steps were taken. The start time must be equal to or greater than the end time of the previous record. Adding all of the values together for a period of time calculates the total number of steps during that period.
