ExerciseUpdate.ActiveDurationCheckpoint Artifact: androidx.health:health-services-client View Source Added in 1.0.0 Kotlin | Java public final class ExerciseUpdate.ActiveDurationCheckpoint This records the last time the exercise transitioned from an active to an inactive state or from an inactive to an active state, where inactive states match those found in ExerciseState.isPaused or ExerciseState.isEnded . This can be used to calculate the exercise active duration in a way that is consistent with Health Service's view of the exercise. If the exercise is currently inactive, the exercise’s active duration will match activeDuration below. If the exercise is active, the active duration can be calculated by activeDuration + (now() - time) .
