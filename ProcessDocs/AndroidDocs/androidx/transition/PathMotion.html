PatternPathMotion A PathMotion that takes a Path pattern and applies it to the separation between two points. This base class can be extended to provide motion along a Path to Transitions. Transitions such as android.transition.ChangeBounds move Views, typically in a straight path between the start and end positions. Applications that desire to have these motions move in a curve can change how Views interpolate in two dimensions by extending PathMotion and implementing getPath .
