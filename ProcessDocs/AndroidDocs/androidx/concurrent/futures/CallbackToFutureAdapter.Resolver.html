CallbackToFutureAdapter.Resolver Artifact: androidx.concurrent:concurrent-futures View Source Added in 1.0.0 Kotlin | Java public interface CallbackToFutureAdapter.Resolver <T> This interface should be implemented by the object passed into getFuture . Implementations are responsible to resolve passed Completer object to success or failure inline or in the response to some other callback. This interface creates a logical scope for the code that resolves a future returned from getFuture and separates it from outer scope that works with that future as adding listeners etc. This separation allows us to detect situations when the returned future isn't done, but the completer object was garbage collected, and fail the future appropriately instead of keeping the future and its listeners chain forever.
