The draw surface is used for all operations except for any pixel data read back or copy operations which are taken from the read surface. The same EGLSurface may be specified for both draw and read surfaces. If the context is not previously configured, the only valid parameters for the draw and read surfaces is EGL14.EGL_NO_SURFACE . This is useful to make sure there is always a surface specified and to release the current context without assigning a new one.
