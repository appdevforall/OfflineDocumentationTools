JavaScriptReplyProxy Artifact: androidx.webkit:webkit View Source Added in 1.3.0 Kotlin | Java @ UiThread public abstract class JavaScriptReplyProxy This class represents the JavaScript object injected by WebViewCompat#addWebMessageListener .
