UiThreadTestRule Artifact: androidx.test:rules View Source Kotlin | Java public class UiThreadTestRule implements TestRule This class is deprecated. use UiThreadTest directly without this rule. UiThreadTest is now supported as part of the core Android test runner to provide the ability to run methods annotated with @Before and @After on the UI thread regardless of what @Test is annotated with. This rule allows the test method annotated with UiThreadTest to execute on the application's main thread (or UI thread). Note, methods annotated with Before and After will also be executed on the UI thread. See also UiThreadTest if you need to switch in and out of the UI thread within your method.
