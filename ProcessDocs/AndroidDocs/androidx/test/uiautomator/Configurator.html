Configurator Artifact: androidx.test.uiautomator:uiautomator View Source Added in 2.2.0 Kotlin | Java public final class Configurator Allows you to set key parameters for running UiAutomator tests. The new settings take effect immediately and can be changed at any time during a test run. To modify parameters, first obtain an instance by calling getInstance . As a best practice, make sure you always save the original value of any parameter that you are modifying. After running your tests with the modified parameters, make sure to also restore the original parameter values, otherwise this will impact other tests cases.
