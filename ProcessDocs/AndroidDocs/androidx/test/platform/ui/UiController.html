UiController Artifact: androidx.test:monitor View Source Kotlin | Java public interface UiController Provides base-level UI operations (such as injection of MotionEvent s) that can be used to build user actions such as clicks, scrolls, swipes, etc. This replaces parts of the android Instrumentation class that provides similar functionality. However, it provides a more advanced synchronization mechanism for test actions. The key differentiators are: test actions are assumed to be called on the main thread after a test action is initiated, execution blocks until all messages in the main message queue have been cleared.
