InstrumentationRegistry Artifact: androidx.test:monitor View Source Kotlin | Java public final class InstrumentationRegistry An exposed registry instance that holds a reference to the instrumentation running in the process and its arguments. Instrumentation and InstrumentationRegistry are low level APIs, typically used by higher level test frameworks. It is generally not recommended for direct use by most tests.
