Public methods getInstance synchronized public static  PlatformTestStorage   getInstance () Returns the registered PlatformTestStorage instance. By default, a FileTestStorage implementation is used. The default implementation is currently recommended for users using android gradle plugins version 8.0 or greater which supports writing output files (only). Gradle users using versions 8.0 or greater can optionally also opt in the test services TestStorage implementation by adding the following configuration to their build.gradle file: defaultConfig { testInstrumentationRunnerArguments useTestStorageService: "true" } dependencies { androidTestUtil "androidx.test.services:test-services:$servicesVersion" } This method returns the instance last registered by the registerInstance method, or the default instance if none is ever registered.
