PlatformTestStorage Artifact: androidx.test:monitor View Source Kotlin | Java public interface PlatformTestStorage An interface representing on-device I/O operations in an Android test. This API allows users to retrieve test data specified in the build configuration, and write output test data that can be automatically collected by the test runner infrastructure, if the environment supports it. Typically users will retrieve the appropriate implementation via getInstance . Implementers would need to also implement the appropriate test runner support for pushing and pulling the test data to and from the device from the build environment.
