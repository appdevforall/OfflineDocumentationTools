ThemedSpinnerAdapter Artifact: androidx.appcompat:appcompat View Source Added in 1.1.0 Kotlin | Java public interface ThemedSpinnerAdapter extends SpinnerAdapter An extension of SpinnerAdapter that is capable of inflating drop-down views against a different theme than normal views. Classes that implement this interface should use the theme provided to setDropDownViewTheme when creating views in getDropDownView . The Helper class is provided to aide implementation in a backwards compatible way.
