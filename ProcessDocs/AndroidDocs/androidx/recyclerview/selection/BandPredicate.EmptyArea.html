BandPredicate.EmptyArea Artifact: androidx.recyclerview:recyclerview-selection View Source Added in 1.0.0 Kotlin | Java public final class BandPredicate.EmptyArea extends BandPredicate java.lang.Object    ↳ androidx.recyclerview.selection.BandPredicate      ↳ androidx.recyclerview.selection.BandPredicate.EmptyArea A BandPredicate that allows initiation of band selection only in areas of RecyclerView that map to NO_POSITION . In most cases, this will be the empty areas between views. Use this implementation to permit band selection only in empty areas surrounding view items. But be advised that if there is no empy area around view items, band selection cannot be initiated.
