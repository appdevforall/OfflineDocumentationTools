AsyncListUtil Artifact: androidx.recyclerview:recyclerview View Source Added in 1.0.0 Kotlin | Java public class AsyncListUtil <T> A utility class that supports asynchronous content loading. It can be used to load Cursor data in chunks without querying the Cursor on the UI Thread while keeping UI and cache synchronous for better user experience. It loads the data on a background thread and keeps only a limited number of fixed sized chunks in memory at all times. AsyncListUtil queries the currently visible range through ViewCallback , loads the required data items in the background through DataCallback , and notifies a ViewCallback when the data is loaded. It may load some extra items for smoother scrolling. Note that this class uses a single thread to load the data, so it suitable to load data from secondary storage such as disk, but not from network. This class is designed to work with RecyclerView , but it does not depend on it and can be used with other list views.
