NavGraph Artifact: androidx.navigation:navigation-common View Source Added in 1.0.0 Kotlin | Java public class NavGraph extends NavDestination implements Iterable java.lang.Object    ↳ androidx.navigation.NavDestination      ↳ androidx.navigation.NavGraph Known direct subclasses DynamicGraphNavigator.DynamicNavGraph DynamicGraphNavigator.DynamicNavGraph The NavGraph for dynamic features. NavGraph is a collection of NavDestination nodes fetchable by ID. A NavGraph serves as a 'virtual' destination: while the NavGraph itself will not appear on the back stack, navigating to the NavGraph will cause the getStartDestination to be added to the back stack. Construct a new NavGraph. This NavGraph is not valid until you add a destination and set the starting destination .
