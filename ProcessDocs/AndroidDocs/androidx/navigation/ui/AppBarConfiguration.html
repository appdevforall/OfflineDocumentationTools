Returns true if the NavDestination was added directly as a top level destination via AppBarConfiguration.Builder constructors such as AppBarConfiguration.Builder(topLevelDestinationIds: Set<Int>) . If destination was added with a AppBarConfiguration.Builder that could take in a graph, i.e. AppBarConfiguration.Builder(NavGraph) or AppBarConfiguration.Builder(Menu) , this helper will return true if the destination is the start destination of a graph (including nested graphs i.e. MenuItem that are also NavGraph ), or an individual MenuItem within the Menu .
