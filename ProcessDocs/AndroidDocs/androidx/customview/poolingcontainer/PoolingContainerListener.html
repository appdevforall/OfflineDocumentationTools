PoolingContainerListener Artifact: androidx.customview:customview-poolingcontainer View Source Added in 1.0.0 Kotlin | Java public fun interface PoolingContainerListener A callback to inform a child View within a container that manages its children's lifecycle outside of the View hierarchy (such as a RecyclerView) when that child should dispose any resources it holds. This callback is not necessarily triggered if the pooling container is disassociating the View from a particular piece of data (that is, it is not an "unbind listener"). It is intended for expensive resources that need to be cached across data items, but need a signal to be disposed of.
