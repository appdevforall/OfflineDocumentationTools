ViewDragHelper Artifact: androidx.customview:customview View Source Added in 1.0.0 Kotlin | Java public class ViewDragHelper ViewDragHelper is a utility class for writing custom ViewGroups. It offers a number of useful operations and state tracking for allowing a user to drag and reposition views within their parent ViewGroup.
