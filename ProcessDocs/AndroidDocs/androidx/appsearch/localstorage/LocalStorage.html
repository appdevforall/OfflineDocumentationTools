LocalStorage Artifact: androidx.appsearch:appsearch-local-storage View Source Added in 1.1.0 Kotlin | Java public class LocalStorage An AppSearch storage system which stores data locally in the app's storage space using a bundled version of the search native library. The search native library is an on-device searching library that allows apps to define androidx.appsearch.app.AppSearchSchema s, save and query a variety of Document s. The library needs to be initialized before using, which will create a folder to save data in the app's storage space. Queries are executed multi-threaded, but a single thread is used for mutate requests (put, delete, etc..).
