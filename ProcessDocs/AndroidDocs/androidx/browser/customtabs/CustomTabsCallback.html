CustomTabsCallback Artifact: androidx.browser:browser View Source Added in 1.2.0 Kotlin | Java public class CustomTabsCallback A callback class for custom tabs client to get messages regarding events in their custom tabs. In the implementation, all callbacks are sent to the UI thread for the client.
