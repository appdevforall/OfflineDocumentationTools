RemotePlaybackClient Artifact: androidx.mediarouter:mediarouter View Source Added in 1.1.0 Kotlin | Java public class RemotePlaybackClient A helper class for playing media on remote routes using the remote playback protocol defined by MediaControlIntent . The client maintains session state and offers a simplified interface for issuing remote playback media control intents to a single route.
