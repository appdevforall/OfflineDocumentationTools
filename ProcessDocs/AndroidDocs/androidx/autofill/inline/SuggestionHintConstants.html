SuggestionHintConstants Artifact: androidx.autofill:autofill View Source Added in 1.1.0 Kotlin | Java @ RequiresApi (api = Build.VERSION_CODES.R) public final class SuggestionHintConstants Contains all the officially supported Autofill inline suggestion hint constants. Set through the inline suggestion content builder, such as setHints to provide hints about the type of the suggestion content. The remote process that shows the inline suggestion may not have access to the suggestion content, but it can use the associated hints to help rank and evaluate the quality of the suggestion based on user action on them.
