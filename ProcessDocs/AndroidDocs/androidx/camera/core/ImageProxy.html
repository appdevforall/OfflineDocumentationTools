If the ImageProxy is a wrapper for an android Image , it will return the Image . It is possible for an ImageProxy to wrap something that isn't an Image . If that's the case then it will return null. The returned image should not be closed by the application. Instead it should be closed by the ImageProxy, which happens, for example, on return from the ImageAnalysis.Analyzer function. Destroying the ImageAnalysis will close the underlying android.media.ImageReader . So an Image obtained with this method will behave as such. Returns @ Nullable Image the android image.
