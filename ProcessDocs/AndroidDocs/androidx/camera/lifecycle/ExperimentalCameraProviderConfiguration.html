ExperimentalCameraProviderConfiguration Artifact: androidx.camera:camera-lifecycle View Source Added in 1.0.0 Kotlin | Java @ Retention (value = CLASS) @ RequiresOptIn public annotation ExperimentalCameraProviderConfiguration Denotes that the annotated method uses an experimental path for configuring a camera provider. In future releases, this experimental path may be modified or removed completely. Non-experimental methods for initializing a camera provider include implementing androidx.camera.core.CameraXConfig.Provider in the application's android.app.Application class, or by simply using getInstance , which will use a default configuration if none is explicitly configured.
