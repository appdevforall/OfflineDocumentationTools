KeyedAppStatesCallback Artifact: androidx.enterprise:enterprise-feedback View Source Added in 1.1.0-rc01 Kotlin | Java public interface KeyedAppStatesCallback Interface used to listen for the result when using setStates or setStatesImmediate . onResult will only only report errors which occur inside this app. If a failure occurs in the Device Policy Controller then this will not be reported. STATUS_SUCCESS will be reported if the states are sent to all Device Policy Controllers.
