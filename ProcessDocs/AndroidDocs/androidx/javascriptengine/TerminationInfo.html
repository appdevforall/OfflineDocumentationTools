Constants STATUS_MEMORY_LIMIT_EXCEEDED Added in 1.0.0 public static final int  STATUS_MEMORY_LIMIT_EXCEEDED = 3 The isolate exceeded its heap size limit. The isolate may continue to hold onto resources (even if explicitly closed) until the sandbox has been shutdown. If necessary, restart the sandbox at the earliest opportunity in order to reclaim these resources. Note that memory exhaustion will kill the whole sandbox, so any other isolates within the same sandbox will be terminated with STATUS_SANDBOX_DEAD .
