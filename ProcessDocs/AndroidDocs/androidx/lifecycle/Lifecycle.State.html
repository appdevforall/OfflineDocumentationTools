DESTROYED Lifecycle.State   Lifecycle.State.DESTROYED Destroyed state for a LifecycleOwner. After this event, this Lifecycle will not dispatch any more events. INITIALIZED Lifecycle.State   Lifecycle.State.INITIALIZED Initialized state for a LifecycleOwner.
