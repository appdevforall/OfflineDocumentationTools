The Action buttons in Map Based Template are automatically adjusted based on the screen size. On narrow width screen, icon Action s show by default. If no icon specify, showing title Action s instead. On wider width screen, title Action s show by default. If no title specify, showing icon Action s instead. Requirements This template allows up to 4 Action s in its ActionStrip . Of the 4 allowed Action s, it can either be a title Action as set via setTitle, or a icon Action as set via setIcon .
