The Distance instance will be displayed by the host in a localized format, so that it will be consistent with the rest of the user interface where distance information are displayed. For example, the following code creates a string that shows the distance as the first text in the string before the interpunct: String interpunct = "\\u00b7"; SpannableString string = new SpannableString(" " + interpunct + " Point-of-Interest 1"); string.setSpan( DistanceSpan.create( Distance.create(1000, "1.0", UNIT_KILOMETERS)), 0, 1, SPAN_INCLUSIVE_INCLUSIVE); The span flags (e.g. SPAN_EXCLUSIVE_EXCLUSIVE) will be ignored.
