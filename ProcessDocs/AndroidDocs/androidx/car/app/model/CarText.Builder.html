Only CarSpan type spans are allowed in a CarText , other spans will be removed from the provided CharSequence . The text variants should be added in order of preference, from most to least preferred (for instance, from longest to shortest). If the text provided via Builder does not fit in the screen, the host will display the first variant that fits in the screen. For instance, if the variant order is ["long string", "shorter", "short"], and the screen can fit 7 characters, "shorter" will be chosen. However, if the order is ["short", "shorter", "long string"], "short" will be chosen, because "short" fits within the 7 character limit.
