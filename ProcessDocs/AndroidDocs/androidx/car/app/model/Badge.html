Badge Artifact: androidx.car.app:app View Source Added in 1.4.0 Kotlin | Java @ CarProtocol @ ExperimentalCarApi public class Badge Represents a badge that can be displayed as an overlay on top of an image. A badge denotes some sort of call to action, notification, alert, etc. An example is badging of application icons in a launcher to add a number which denotes how many active notifications that application has. Badges may have a dot which is a colored circle appearing in a different location to the icon. Summary Nested types public final class Badge.Builder A builder of Badge .
