Selectable lists, where allowed by the template they are added to, automatically display an item in a selected state when selected by the user. The items in the list define a mutually exclusive selection scope: only a single item will be selected at any given time. The specific way in which the selection will be visualized depends on the template and the host implementation. For example, some templates may display the list as a radio button group, while others may highlight the selected item's background.
