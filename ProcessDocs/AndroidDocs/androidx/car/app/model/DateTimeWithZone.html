DateTimeWithZone Artifact: androidx.car.app:app View Source Added in 1.0.0 Kotlin | Java @ CarProtocol public final class DateTimeWithZone A time with an associated time zone information. In order to avoid time zone databases being out of sync between the app and the host, this model avoids using IANA database time zone IDs and instead relies on the app passing the time zone offset and its abbreviated name. Apps can use their time library of choice to retrieve the time zone information. create and create are provided for convenience if using java.util and java.time respectively. If using another library such as Joda time, create can be used.
