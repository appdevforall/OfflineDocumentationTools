The following types are supported: TYPE_BITMAP TYPE_RESOURCE TYPE_URI TYPE_URI is only supported in templates that explicitly allow it. In those cases, the appropriate APIs will be documented to indicate this. For TYPE_URI , the URI's scheme must be SCHEME_CONTENT . If the icon image is loaded from URI, it may be cached on the host side. Changing the contents of the URI will result in the host showing a stale image. This tint overrides the tint set through setTint in the backing IconCompat with a CarColor tint. The tint set through setTint is not guaranteed to be applied if the CarIcon tint is not set. The tint mode used to blend this color is SRC_IN . Depending on contrast requirements, capabilities of the vehicle screens, or other factors, the color may be ignored by the host or overridden by the vehicle system.
