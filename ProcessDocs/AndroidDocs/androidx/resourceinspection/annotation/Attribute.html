This annotation is consumed by the androidx.resourceinspection:resourceinspection-processor annotation processor to map a getter on a custom android.view.View back to its XML attribute name and ID. This enables Android Studio's layout inspection tool to read the runtime values of the attributes of a custom android.view.View . Populating this field with an array of IntMap entries provides the layout inspection tool with the semantic names of enumerations stored as integers, instead of the numeric value. This is used for attributes with an androidx.annotation.IntDef mapping to flags or enumerations. By default, the annotation processor assumes that the mapping defines an enumeration. If any one of the entries has its mask set, the mapping will be interpreted as flags.
