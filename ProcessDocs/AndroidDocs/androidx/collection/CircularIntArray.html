CircularIntArray Artifact: androidx.collection:collection View Source Added in 1.0.0 Kotlin | Java public final class CircularIntArray CircularIntArray is a circular integer array data structure that provides O(1) random read, O(1) prepend and O(1) append. The CircularIntArray automatically grows its capacity when number of added integers is over its capacity.
