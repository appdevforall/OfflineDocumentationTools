Loader.OnLoadCanceledListener Artifact: androidx.loader:loader View Source Added in 1.0.0 Kotlin | Java public interface Loader.OnLoadCanceledListener <D> Interface that is implemented to discover when a Loader has been canceled before it finished loading its data. You do not normally need to implement this yourself; it is used in the implementation of LoaderManager to find out when a Loader it is managing has been canceled so that it can schedule the next Loader. This interface should only be used if a Loader is not being used in conjunction with LoaderManager.
