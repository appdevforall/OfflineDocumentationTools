Builder to construct a header row. A header provides some additional functionality compared to a RowBuilder . Like a row, a header has a title, subtitle, and primary action. In addition to a row's title, subtitle, and primary action, a header also supports setting a summary description of the list contents using setSummary . This summary might be used when the rest of the list content is not shown (e.g. if SliceView presenting slice is configured to MODE_SMALL . The primary action specified by setPrimaryAction will be used as the PendingIntent sent when header is clicked. This action is also used when when SliceView displays in MODE_SHORTCUT . Unlike row builder, header builder does not support end items (e.g. addEndItem ). The header may be used to display actions set on the list via addAction .
