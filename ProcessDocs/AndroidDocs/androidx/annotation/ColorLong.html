ColorLong Artifact: androidx.annotation:annotation View Source Added in 1.0.0 Kotlin | Java @ MustBeDocumented @ Retention (value = AnnotationRetention.SOURCE) @ Target (allowedTargets = [AnnotationTarget.VALUE_PARAMETER, AnnotationTarget.FUNCTION, AnnotationTarget.PROPERTY_GETTER, AnnotationTarget.PROPERTY_SETTER, AnnotationTarget.LOCAL_VARIABLE, AnnotationTarget.FIELD]) public annotation ColorLong Denotes that the annotated element represents a packed color long. If applied to a long array, every element in the array represents a color long. For more information on how colors are packed in a long, please refer to the documentation of the android.graphics.Color class.
