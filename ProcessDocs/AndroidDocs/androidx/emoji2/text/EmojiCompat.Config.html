By default EmojiCompat will start loading the metadata during init . When set to LOAD_STRATEGY_MANUAL , you should call load to initiate metadata loading. Default implementations of EmojiCompat.MetadataRepoLoader start a thread during their load functions. Just instantiating and starting a thread might take time especially in older devices. Since init has to be called before any EmojiCompat widgets are inflated, this results in time spent either on your Application.onCreate or Activity .onCreate. If you'd like to gain more control on when to start loading the metadata and be able to call init with absolute minimum time cost you can use LOAD_STRATEGY_MANUAL . When set to LOAD_STRATEGY_MANUAL , EmojiCompat will wait for load to be called by the developer in order to start loading metadata, therefore you should call load to initiate metadata loading. load can be called from any thread.
