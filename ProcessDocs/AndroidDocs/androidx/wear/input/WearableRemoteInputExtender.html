The default action type is "send." Parameters int imeActionType Action type to be set on RemoteInput session. Should be one of the following values: EditorInfo.IME_ACTION_SEND , EditorInfo.IME_ACTION_SEARCH , EditorInfo.IME_ACTION_DONE , EditorInfo.IME_ACTION_GO . If not, send action will be set.
