Material components provide proper defaults for the background image. In order to take advantage of those defaults, this should be used with the resource ID only: backgroundImage("id") . This image can have optional overlay on top of it, that is usually a dark color with opacity. This is highly recommended to be added when there's additional content like text on top of image, to improve readability. If this is used in imageButton as image button with no other content, overlayColor can be omitted, and the overlay color on top of the image would be ignored.
