For more info see: https://developer.android.com/training/wearables/wff Implement to allow your Renderers to share data with SharedAssets. When editing multiple WatchFaceService , instances and hence Renderers can exist concurrently (e.g. a headless instance and an interactive instance). Using SharedAssets allows memory to be saved by sharing immutable data (e.g. Bitmaps, shaders, etc...) between them. To take advantage of SharedAssets, override this method. The constructed SharedAssets are passed into the render as an argument (NB you'll have to cast this to your type). When all instances using SharedAssets have been closed, SharedAssets.onDestroy will be called. Note that while SharedAssets are constructed on a background thread, they'll typically be used on the main thread and subsequently destroyed there.
