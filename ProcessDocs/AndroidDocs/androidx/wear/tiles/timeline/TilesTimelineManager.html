TilesTimelineManager Artifact: androidx.wear.tiles:tiles-renderer View Source Added in 1.0.0 Kotlin | Java public class TilesTimelineManager implements AutoCloseable Manager for a single Wear Tiles timeline. This handles the dispatching of single Tile layouts from a full timeline. It will set the correct alarms to detect when a layout should be updated, and dispatch it to its listener.
