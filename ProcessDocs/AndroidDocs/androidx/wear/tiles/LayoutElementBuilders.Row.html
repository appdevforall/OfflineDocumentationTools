LayoutElementBuilders.Row Artifact: androidx.wear.tiles:tiles View Source Added in 1.0.0 Deprecated in 1.2.0 Kotlin | Java public final class LayoutElementBuilders.Row implements LayoutElementBuilders.LayoutElement A row of elements. Each child will be laid out horizontally, one after another (i.e. stacking to the right). This element will size itself to the smallest size required to hold all of its children (e.g. if it contains three elements sized 10x10, 20x20 and 30x30, the resulting row will be 60x30). If specified, vertical_alignment can be used to control the gravity inside the container, affecting the vertical placement of children whose width are smaller than the resulting row height.
