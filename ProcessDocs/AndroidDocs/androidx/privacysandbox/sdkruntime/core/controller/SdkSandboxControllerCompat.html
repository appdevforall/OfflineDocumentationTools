Controller that is used by SDK loaded in the sandbox or locally to access information provided by the sandbox environment. It enables the SDK to communicate with other SDKS and know about the state of the sdks that are currently loaded. An instance can be obtained using SdkSandboxControllerCompat.from . The Context can be obtained using SandboxedSdkProviderCompat.context .
