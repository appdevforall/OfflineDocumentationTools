For images which are largely made up of people's faces then this value should be increased to ~24. resizeBitmapArea Added in 1.0.0 public @ NonNull Palette.Builder   resizeBitmapArea (int area) Set the resize value when using a android.graphics.Bitmap as the source. If the bitmap's area is greater than the value specified, then the bitmap will be resized so that its area matches area . If the bitmap is smaller or equal, the original is used as-is. This value has a large effect on the processing time. The larger the resized image is, the greater time it will take to generate the palette. The smaller the image is, the more detail is lost in the resulting image and thus less precision for color selection.
