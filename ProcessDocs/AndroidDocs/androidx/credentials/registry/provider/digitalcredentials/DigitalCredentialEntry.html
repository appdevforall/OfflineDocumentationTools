A digital credential entry to be registered. This entry contains information that serves two major purposes: Credential metadata for filtering / request matching purpose. When another app makes a CredentialManager.getCredential request, it will specify the specific credential properties it is looking for. The Credential Manager will use the info stored for the given entry and the registry matcher you registered to determine whether this entry can fulfill an incoming request. Display metadata that will be rendered as part of the Credential Manager selector UI. The selector UI, post filtering, will display to the user their qualified, available credential candidates, in order for the user to make an informed choice. All display metadata will be contained in the entryDisplayData property.
