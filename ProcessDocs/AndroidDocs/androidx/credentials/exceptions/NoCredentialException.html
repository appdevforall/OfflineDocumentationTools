This can be caused by various scenarios such as that the user doesn't have any credential or the user doesn't grant consent to using any available credential. Upon this exception, your app should navigate to use the regular app sign-up or sign-in screen. When that succeeds, you should invoke androidx.credentials.CredentialManager.createCredential (kotlin) or androidx.credentials.CredentialManager.createCredentialAsync (java) to store the login info, so that your user can sign in more easily through Credential Manager the next time.
