BeginCreateCredentialResponse Artifact: androidx.credentials:credentials View Source Added in 1.2.0 Kotlin | Java public final class BeginCreateCredentialResponse Response to BeginCreateCredentialRequest . Credential providers must add a list of CreateEntry , and an optional RemoteEntry to this response. Each CreateEntry is displayed to the user on the account selector, as an account option where the given credential can be stored. A RemoteEntry is an entry on the selector, through which user can choose to create the credential on a remote device.
