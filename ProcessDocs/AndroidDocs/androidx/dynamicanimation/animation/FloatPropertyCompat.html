FloatPropertyCompat is an abstraction that can be used to represent a mutable float value that is held in a host object. To access this float value, setValue and getter getValue need to be implemented. Both the setter and the getter take the primitive float type and avoids autoboxing and other overhead associated with the Float class. For API 24 and later, FloatProperty instances can be converted to FloatPropertyCompat through createFloatPropertyCompat .
