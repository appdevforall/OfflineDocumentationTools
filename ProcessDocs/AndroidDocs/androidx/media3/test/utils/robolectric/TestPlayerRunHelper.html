TestPlayerRunHelper Artifact: androidx.media3:media3-test-utils-robolectric View Source Kotlin | Java @ UnstableApi public final class TestPlayerRunHelper Helper methods to block the calling thread until the provided ExoPlayer instance reaches a particular state. This class has two usage modes: Fluent method chaining, e.g. run(player).ignoringNonFatalErrors().untilState(STATE_ENDED) . Single method call, e.g. runUntilPlaybackState(player, STATE_ENDED) . New usages should prefer the fluent method chaining, and new functionality will only be added to this form. The older single methods will be kept for backwards compatibility.
