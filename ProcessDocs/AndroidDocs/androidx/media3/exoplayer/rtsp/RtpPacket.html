The size of the target buffer and the length argument should be big enough so that the entire RTP packet could fit. That is, if there is not enough space to store the entire RTP packet, no bytes will be written. The maximum size of an RTP packet is defined as MAX_SIZE . Parameters byte[] target A target byte buffer to which the packet data is copied. int offset The offset into the target array at which to write. int length The maximum number of bytes that can be written. Returns int The number of bytes written, or LENGTH_UNSET if there is not enough space to write the packet.
