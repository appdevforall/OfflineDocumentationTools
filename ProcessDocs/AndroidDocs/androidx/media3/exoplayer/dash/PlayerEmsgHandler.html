PlayerEmsgHandler Artifact: androidx.media3:media3-exoplayer-dash View Source Kotlin | Java @ UnstableApi public final class PlayerEmsgHandler implements Handler.Callback Handles all emsg messages from all media tracks for the player. This class will only respond to emsg messages which have schemeIdUri "urn:mpeg:dash:event:2012", and value "1"/"2"/"3". When it encounters one of these messages, it will handle the message according to Section 4.5.2.1 DASH -IF IOP Version 4.1: If both presentation time delta and event duration are zero, it means the media presentation has ended. Else, it will parse the message data from the emsg message to find the publishTime of the expired manifest, and mark manifest with publishTime smaller than that values to be expired. In both cases, the DASH media source will be notified, and a manifest reload should be triggered.
