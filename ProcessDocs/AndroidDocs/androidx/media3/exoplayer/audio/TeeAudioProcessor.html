TeeAudioProcessor Artifact: androidx.media3:media3-exoplayer View Source Kotlin | Java @ UnstableApi public final class TeeAudioProcessor extends BaseAudioProcessor java.lang.Object    ↳ androidx.media3.common.audio.BaseAudioProcessor      ↳ androidx.media3.exoplayer.audio.TeeAudioProcessor Audio processor that outputs its input unmodified and also outputs its input to a given sink. This is intended to be used for diagnostics and debugging. This audio processor can be inserted into the audio processor chain to access audio data before/after particular processing steps have been applied. For example, to get audio output after playback speed adjustment and silence skipping have been applied it is necessary to pass a custom AudioProcessorChain when creating the audio sink, and include this audio processor after all other audio processors.
