See also createPeriod getInitialTimeline public @ Nullable Timeline   getInitialTimeline () Returns the initial placeholder timeline that is returned immediately when the real timeline is not yet known, or null to let the player create an initial timeline. Should not be called directly from application code. The initial timeline must use the same uids for windows and periods that the real timeline will use. It also must provide windows which are marked as dynamic to indicate that the window is expected to change when the real timeline arrives. Any media source which has multiple windows should typically provide such an initial timeline to make sure the player reports the correct number of windows immediately.
