Instead of providing a media notification that is completely custom, a developer can set this style and still obtain system decorations like the notification header with the expand affordance and actions. Use #setCustomContentView(RemoteViews) , #setCustomBigContentView(RemoteViews) and #setCustomHeadsUpContentView(RemoteViews) to set the corresponding custom views to display. To use this style with your Notification, feed it to #setStyle(androidx.core.app.NotificationCompat.Style) like so: Notification noti = new NotificationCompat.Builder() .setSmallIcon(androidx.media3.R.drawable.media3_notification_small_icon) .setLargeIcon(albumArtBitmap)) .setCustomContentView(contentView) .setStyle( new NotificationCompat.DecoratedMediaCustomViewStyle() .setMediaSession(mySession)) .build(); If you are using this style, consider using the corresponding styles like TextAppearance_Compat_Notification_Media or TextAppearance_Compat_Notification_Title_Media in your custom views in order to get the correct styling on each platform version.
