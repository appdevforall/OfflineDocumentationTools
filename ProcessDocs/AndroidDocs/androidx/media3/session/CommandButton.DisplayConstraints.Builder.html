Sets the maximum number of buttons that can be displayed in a slot.

The default values are:

  • SLOT_CENTRAL, SLOT_BACK, SLOT_FORWARD: 1
  • SLOT_BACK_SECONDARY, SLOT_FORWARD_SECONDARY: 0
  • SLOT_OVERFLOW: MAX_VALUE.
