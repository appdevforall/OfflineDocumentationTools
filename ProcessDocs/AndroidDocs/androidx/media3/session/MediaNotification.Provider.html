Provides media notifications to be posted as notifications that reflect the state of a MediaController and to send media commands to a . The provider is required to create a notification channel , which is required to show notification for SDK_INT >= 26 . All methods will be called on the application thread of the Player associated with the MediaSession the notification is provided for.
