A supplier for a position. Convenience methods and classes for creating position suppliers: Use getConstant for constant or non-moving positions. Use getExtrapolating for positions advancing with the system clock from a provided start time. Use LivePositionSupplier for positions that can be directly obtained from a live system. Note that these suppliers should be disconnected from the live source as soon as the position is no longer valid, for example after a position discontinuity.
