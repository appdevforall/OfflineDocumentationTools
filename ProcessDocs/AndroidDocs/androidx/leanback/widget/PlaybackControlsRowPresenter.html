Typically this row will be the first row in a fragment such as the androidx.leanback.app.PlaybackFragment . The detailed description is rendered using a Presenter passed in PlaybackControlsRowPresenter . Typically this will be an instance of AbstractDetailsDescriptionPresenter . The application can access the detailed description ViewHolder from mDescriptionViewHolder .
