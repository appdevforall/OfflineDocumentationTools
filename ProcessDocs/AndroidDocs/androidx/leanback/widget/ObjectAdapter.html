Artifact: androidx.leanback:leanback

Added in 1.1.0
Kotlin |Java 

public abstract class ObjectAdapter

Known direct subclasses
ArrayObjectAdapter, CursorObjectAdapter, PagingDataAdapter, SparseArrayObjectAdapter
ArrayObjectAdapter

An ObjectAdapter implemented with an ArrayList.
CursorObjectAdapter

An ObjectAdapter implemented with a Cursor.
PagingDataAdapter

An ObjectAdapter implemented with an AsyncPagingDataDiffer.
SparseArrayObjectAdapter

An ObjectAdapter implemented with a android.util.SparseArray.

Base class adapter to be used in leanback activities. Provides access to a data model and is decoupled from the presentation of the items via PresenterSelector.

Nested types
public abstract class ObjectAdapter.DataObserver
