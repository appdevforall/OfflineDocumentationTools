A DetailsFragment renders the elements of its ObjectAdapter as a set of rows in a vertical list.The Adapter's PresenterSelector must maintain subclasses of RowPresenter . When FullWidthDetailsOverviewRowPresenter is found in adapter, DetailsFragment will setup default behavior of the DetailsOverviewRow: The alignment of FullWidthDetailsOverviewRowPresenter is setup in setupDetailsOverviewRowPresenter . The view status switching of FullWidthDetailsOverviewRowPresenter is done in onSetDetailsOverviewRowStatus . The recommended activity themes to use with a DetailsFragment are Theme_Leanback_Details with activity shared element transition for FullWidthDetailsOverviewRowPresenter . Theme_Leanback_Details_NoSharedElementTransition if shared element transition is not needed, for example if first row is not rendered by FullWidthDetailsOverviewRowPresenter . DetailsFragment can use DetailsFragmentBackgroundController to add a parallax drawable background and embedded video playing fragment.
