This occurs when the app attempts an operation requiring user-granted permission that has not been provided. For example, creating a calendar event requires access to the calendar content. If the user hasn't granted this permission, this error should be thrown. This is different from AppFunctionDeniedException in that the required permission is missing from the target app, as opposed to the caller.
