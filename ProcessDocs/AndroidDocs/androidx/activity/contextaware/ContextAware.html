A ContextAware class is associated with a Context sometime after the class is instantiated. By adding a OnContextAvailableListener , you can receive a callback for that event. Classes implementing ContextAware are strongly recommended to also implement androidx.lifecycle.LifecycleOwner for providing a more general purpose API for listening for creation and destruction events.
