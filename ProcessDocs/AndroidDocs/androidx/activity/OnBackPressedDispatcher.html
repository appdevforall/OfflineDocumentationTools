This will automatically call addCallback and remove the callback as the lifecycle state changes. As a corollary, if your lifecycle is already at least started , calling this method will result in an immediate call to addCallback . When the LifecycleOwner is destroyed , it will automatically be removed from the list of callbacks. The only time you would need to manually call OnBackPressedCallback.remove is if you'd like to remove the callback prior to destruction of the associated lifecycle. If the Lifecycle is already destroyed when this method is called, the callback will not be added.
