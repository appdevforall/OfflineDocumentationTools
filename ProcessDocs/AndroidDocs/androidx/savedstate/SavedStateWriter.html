SavedStateWriter

Artifact: androidx.savedstate:savedstate
View Source
Added in 1.3.1
Kotlin |Java 

value public final class SavedStateWriter

An inline class that encapsulates an opaque SavedState, and provides an API for writing the platform specific state.
